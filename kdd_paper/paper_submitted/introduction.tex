\section{Introduction}
\label{sec:introduction}

The proliferation of LLMs has created a new optimization challenge: \emph{model routing}---selecting the optimal model for each query from 80+ candidates spanning diverse capabilities and price points~\cite{chen2023frugalgpt, ong2024routellm}.

Existing solutions have critical limitations: \textbf{Static classifiers}~\cite{ong2024routellm} cannot adapt to user-specific distributions. \textbf{Online bandits}~\cite{slivkins2019contextual} adapt but suffer from prohibitive cold-start---hundreds of costly queries wasted before intelligent decisions emerge.

\textbf{Our Insight.} While user distributions vary, the \emph{latent structure} of model expertise is invariant. GPT-4o excels at complex reasoning universally; Nova-Lite dominates structured output tasks. This expertise can be learned offline and \emph{shipped} as a compressed prior.

We introduce a \textbf{Density-Based Warm-Start Framework} that solves cold-start via \emph{Expert Distillation}:
\begin{enumerate}[leftmargin=*]
    \item \textbf{Offline}: Dense evaluation (81 models $\times$ 497 archetypes) using GPT-4o as oracle
    \item \textbf{Compression}: Distill expertise into \textbf{<1MB} covariance matrices
    \item \textbf{Shipping}: Priors give day-one intelligence without exploration
    \item \textbf{Adaptation}: Retain full plasticity via rank-one updates
\end{enumerate}

\textbf{Key Results.} On 2,000 real-world queries: \textbf{63.6\% regret reduction} vs.\ cold-start; \textbf{97.6\% cost savings} on equal-quality queries; \textbf{+6.1\% quality} with 67.7\% cost reduction vs.\ GPT-4o; \textbf{8.94ms} P99 latency (1.1\% overhead).
