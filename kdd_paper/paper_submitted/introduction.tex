\section{Introduction}
\label{sec:introduction}

The proliferation of Large Language Models (LLMs) has fundamentally transformed the deployment landscape. What was once a monolithic space dominated by a handful of frontier generalists has evolved into a fragmented ecosystem comprising over 80 commercially available models with diverse specializations. This ecosystem spans reasoning-optimized frontier models (e.g., GPT-4o, Claude~3.5~Sonnet), domain-specific specialists (e.g., DeepSeek~Coder for programming), and ultra-efficient distillations (e.g., Gemini~Flash~Lite). While this diversity theoretically enables substantial cost reduction through strategic model selection, practitioners face a critical operational challenge: \emph{given a user prompt and quality constraints, how can we automatically identify the most cost-effective model without compromising reliability?}

Existing approaches to this \emph{model routing} problem broadly partition into two paradigms. \emph{Static routing systems} (e.g., RouteLLM~\cite{ong2024routellm}) employ learned classifiers to predict optimal model assignment based on prompt features. While computationally efficient, these methods struggle with distribution shift and cannot adapt to evolving model capabilities. \emph{Cascading frameworks} (e.g., FrugalGPT~\cite{chen2023frugalgpt}) adopt a reactive strategy, sequentially querying models from cheapest to most expensive until output quality is verified. Though adaptive, cascading architectures suffer from fundamental scalability limitations: (1)~linear latency scaling with pool size, as each model must be evaluated sequentially; (2)~manual configuration burden, requiring practitioners to hand-craft model sequences; and (3)~underutilization of long-tail specialists, as latency constraints force short chains that ignore the majority of available models. These limitations become prohibitive as model registries scale beyond single digits ($N > 80$ in production environments).

We present \ours{}, a framework that reconciles adaptivity with scalability through \emph{predictive routing with shippable priors}. Rather than verifying quality ex-post through cascading invocations, \ours{} employs a contextual bandit~\cite{slivkins2019contextual} to estimate model suitability \emph{ex-ante}, before any generation occurs. The key innovation lies in our prior construction: we distill offline expert supervision into compact covariance matrices that capture prompt--difficulty correlations, then ship these priors to production for warm-start initialization. This approach decouples slow offline knowledge distillation from fast online deployment, enabling sub-100-example domain calibration while maintaining $O(1)$ invocations per request (constant-time operation regardless of pool size).

To address the tension between cost optimization and reliability guarantees, we introduce a \emph{tiered architecture} that unifies predictive and reactive strategies. Our standard mode prioritizes cost reduction through pure prediction, establishing a new Pareto frontier for cost-quality trade-offs. However, through systematic evaluation, we identify a failure mode we term \emph{confident failure}: scenarios where plausible-but-incorrect outputs evade reactive verifiers in complex instruction-following domains. To mitigate this, our hybrid mode employs prediction as a gating mechanism for selective verification, dynamically allocating verification budget to high-uncertainty prompts. This design enables smooth interpolation between ``Cost Leader'' and ``High Assurance'' operational regimes via a single tunable parameter ($\lambda$), without requiring architectural modification.

\smallskip
\noindent\textbf{Contributions.} This work makes the following contributions:
\begin{itemize}[leftmargin=*]
    \item \textbf{Shippable Prior Framework:} We introduce a distillation methodology that compresses offline expert supervision into compact covariance priors, enabling cold-start routing with 96--99\% reduction in day-one regret relative to na\"ive bandit initialization ($<$100 calibration examples; \S~\ref{sec:distillation}, \S~\ref{sec:rq1}).
    \item \textbf{Decoupled Scalability Architecture:} We formulate a routing system that separates prompt-difficulty learning from model-capability profiling, allowing new models to be onboarded in constant time via public metadata filters while the bandit autonomously refines predictions through online exploration (\S~\ref{sec:scalability}).
    \item \textbf{Tiered Reliability Mechanism:} We design a hybrid architecture that unifies predictive routing with selective verification, achieving 98\% reliability on instruction-following tasks (vs.\ 95\% for pure cascading) while maintaining tunable cost-quality trade-offs (\S~\ref{sec:hybrid}, \S~\ref{sec:confident_failure}).
    \item \textbf{Large-Scale Empirical Validation:} We evaluate \ours{} on a production-scale registry of 81 models using real-world pricing and performance data. Our results demonstrate a 61\% cost reduction compared to FrugalGPT (\$0.70 vs.\ \$1.78 per 1k queries) with millisecond-scale routing overhead, establishing a new state-of-the-art Pareto frontier (\S~\ref{sec:evaluation}).
\end{itemize}
