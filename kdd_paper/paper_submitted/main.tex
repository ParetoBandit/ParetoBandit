% ABSTRACT
% ============================================================================
\begin{abstract}
The LLM ecosystem is rapidly fragmenting into a ``long tail'' of specialized models that achieve frontier performance at a fraction of the cost. However, existing routing systems fail to scale to this fragmentation: cascading frameworks suffer from $O(N)$ latency and rigid configurations, while online bandits face prohibitive cold-start costs.

We present \ours{}, a scalable routing framework that utilizes \emph{shippable priors}---covariance matrices distilled offline from teacher supervision---to enable $O(1)$ predictive search over massive model pools. With fewer than 100 calibration examples, these priors reduce day-one regret by 96--99\% relative to standard initialization. To handle a fast-moving market, \ours{} decouples prompt difficulty from model capability, allowing new models to be integrated immediately via online exploration. Finally, we introduce a \emph{tiered architecture} that unifies cost and reliability. Standard mode establishes a new Pareto anchor, reducing inference costs by 61\% compared to FrugalGPT (\$0.70 vs.\ \$1.78/1k). Hybrid mode selectively triggers verification for high-risk prompts, addressing the ``confident failure'' phenomenon and outperforming cascading baselines by 3\% on complex instruction-following tasks. \ours{} adds millisecond-scale routing overhead and enables a tunable trade-off between cost and reliability. By exposing sensitivity parameters ($\lambda$), it allows organizations to dynamically shift between ``Cost Leader'' and ``High Assurance'' modes without architectural changes.
\end{abstract}
