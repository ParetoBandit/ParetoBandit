% ABSTRACT
% ============================================================================
\begin{abstract}
The LLM landscape is rapidly fragmenting: alongside frontier models, dozens of low-cost specialists now achieve strong performance on narrow task families. Real deployments therefore face a routing problem---selecting, per query, a model that best trades off quality, cost, and latency across large and changing model pools. Existing routers either (i) rely on fixed cascades that add sequential latency and expose only a small chain of models, or (ii) use online bandits that adapt but incur substantial cold-start exploration cost. Critically, both approaches require expensive offline profiling to add new models.

We present \ours{}, a routing framework that warm-starts contextual bandits using \emph{shippable priors}: compact per-model covariance statistics distilled offline from dense teacher supervision. With fewer than 100 calibration examples, the priors transfer to new domains and substantially reduce day-one regret relative to standard initialization, while preserving online adaptation under drift.

\textbf{Zero-Overhead Scalability.} Unlike static routers that require re-training or cascades that require re-calibration, \ours{} decouples \emph{prompt difficulty} (learned once, model-agnostic) from \emph{model capability} (registered via public metadata). New models are onboarded in $O(1)$ time using only their API endpoint and reported benchmark scores as coarse safety filters; the bandit then autonomously verifies actual performance via online exploration.

\ours{} supports a tiered deployment mode in which the bandit predicts when a query is high-risk and selectively triggers a verification cascade, improving reliability on instruction-following tasks where reactive verification is prone to ``confident failures.'' Across 80+ production models, \ours{} adds millisecond-scale routing overhead and enables a tunable cost--accuracy trade-off suitable for financial and latency SLAs.
\end{abstract}
