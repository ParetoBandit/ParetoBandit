\section{RQ3: Cost-Quality Efficiency}
\label{sec:rq3}

\textbf{Research Question}: What is the business impact of intelligent routing? Can we simultaneously improve quality \emph{and} reduce cost?

This section presents the core value proposition for production deployment.

% ---------------------------------------------------------------------------
% 6.1 The Efficiency Frontier
% ---------------------------------------------------------------------------

\subsection{The Pareto Frontier}

Not all routing systems are created equal. Some offer high accuracy at premium prices; others sacrifice quality for cost savings. The key insight is that \emph{predictive routing can outperform both extremes}---by dynamically selecting specialists, the router defines a new efficient frontier.

Figure~\ref{fig:pareto} visualizes the cost-accuracy trade-off across routing strategies.

\begin{figure}[t]
    \centering
    \includegraphics[width=\columnwidth]{figures/figure4_pareto_frontier.pdf}
    \caption{\textbf{RQ3: The Tiered Architecture Pareto Frontier.} Left: Cost vs.\ System Accuracy (macro-average of Math/Reasoning/MMLU/Instruction) for each routing strategy. BanditGPT's Standard Mode achieves the lowest cost (\$0.67/1k), while Hybrid Mode approaches FrugalGPT's accuracy with $O(1)$ scalability over 81+ models. Right: Domain breakdown showing the ``Verifier Trap''---Hybrid beats FrugalGPT on Instructions (98\% vs 95\%) via proactive prediction.}
    \label{fig:pareto}
\end{figure}

\paragraph{Reading the Figure.}
\begin{itemize}[leftmargin=*]
    \item \textbf{Left Panel (Pareto Frontier)}: Each point represents a routing system. The dashed line connects Pareto-optimal strategies where no alternative offers \emph{both} lower cost and higher accuracy.
    \item \textbf{Right Panel (Domain Breakdown)}: Per-domain accuracy reveals where each system excels. Notably, Hybrid outperforms FrugalGPT on Instructions (+3\%) despite similar aggregate accuracy.
    \item \textbf{Tiered Architecture}: BanditGPT offers two operating points---Standard (cost leader) and Hybrid (high-assurance)---controllable via the cascade rate parameter $\lambda$.
\end{itemize}

\paragraph{The Efficiency Insight.} FrugalGPT achieves the highest aggregate accuracy (84.8\%) but is limited to 2--3 models with $O(N)$ latency. BanditGPT's Hybrid mode approaches this accuracy (77.5\%) while enabling $O(1)$ selection over 81+ models. More importantly, Hybrid \emph{beats} FrugalGPT on complex Instructions (98\% vs 95\%) by avoiding the ``Verifier Trap'' (\S\ref{sec:confident_failure}).

\end{itemize}

The router uses GPT-4o \emph{only when necessary}, routing the majority of queries to 97\% cheaper alternatives.

\subsection{Summary: Breaking the Cost-Quality Trade-off}

RQ3 demonstrates that intelligent routing \emph{breaks the traditional cost-quality trade-off}:

\begin{enumerate}[leftmargin=*]
    \item \textbf{Not a Compromise}: The router doesn't sacrifice quality for cost. It achieves \emph{both} +6.1\% quality and $-$67.7\% cost.
    
    \item \textbf{Specialist Discovery}: The router identifies models like Nova-Lite that dominate specific latent regions, achieving 93× better ROI than the generalist baseline.
    
    \item \textbf{Intelligent Fallback}: For complex reasoning and domain expertise (7\% of queries), the router correctly falls back to GPT-4o, preserving quality where it matters.
    
    \item \textbf{Free Efficiency}: For 45\% of queries, both models perform equally---the router captures 97.6\% cost savings without any quality trade-off.
\end{enumerate}

This is the core value proposition for production deployment: \textbf{better quality at lower cost, with no manual tuning required}.
