\section{Cost-Quality Efficiency}
\label{sec:rq3}

\textbf{RQ4}: Can intelligent routing simultaneously improve quality \emph{and} reduce cost?

\subsection{The Pareto Frontier}

Figure~\ref{fig:pareto} visualizes the cost-accuracy trade-off across routing strategies.

\begin{figure}[t]
    \centering
    \includegraphics[width=\columnwidth]{figures/figure4_pareto_frontier.pdf}
    \caption{\textbf{Pareto Frontier.} Left: Cost vs.\ System Accuracy. BanditGPT Standard achieves lowest cost (\$0.67/1k); Hybrid approaches FrugalGPT accuracy with $O(1)$ scalability. Right: Domain breakdown shows Hybrid beats FrugalGPT on Instructions (98\% vs 95\%) via proactive prediction.}
    \label{fig:pareto}
\end{figure}

BanditGPT offers two operating points: \textbf{Standard} (cost leader) and \textbf{Hybrid} (high-assurance), controllable via the cascade rate $\lambda$. Hybrid beats FrugalGPT on Instructions (+3\%) by avoiding the ``Verifier Trap'' (\S\ref{sec:confident_failure}).

\subsection{Production Impact}

For 1M queries/month: GPT-4o costs \$2,190; Nova-Lite costs \$50 (but sacrifices quality); Adaptive Router costs \textbf{\$710} while \emph{improving} quality by 6.1\%. Annual savings: \$17,760 + better user experience. At 10M queries/month: \textbf{\$178,000 annual savings}.

\paragraph{Summary.} Intelligent routing breaks the cost-quality trade-off: +6.1\% quality, $-$67.7\% cost, no manual tuning. The router identifies specialists (93× ROI) and uses expensive models only when necessary.
