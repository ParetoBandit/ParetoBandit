\section{Related Work}
\label{sec:related}

Existing LLM routing approaches fall into three categories, each with limitations that \ours{} addresses.

\textbf{Cascading systems} like FrugalGPT~\cite{chen2023frugalgpt} and RouteLLM~\cite{ong2024routellm} achieve cost savings through sequential model calls, but are typically limited to short, fixed chains that do not exploit large specialist pools. More critically, they rely on \emph{ex-post verification}, which can fail on ``confident failures''---plausible outputs that violate subtle constraints. Both systems also require $O(N)$ profiling to add new models: FrugalGPT needs calibration runs to tune its verifier, while RouteLLM requires re-training its classifier on preference data. \ours{} performs single-pass scoring over 80+ models and uses \emph{ex-ante prediction} to selectively invoke verification for high-risk prompts.

\textbf{Contextual bandits}~\cite{li2010contextual} offer adaptive routing but require $\sim$2,000 queries (\$50--200 exploration cost) before convergence---prohibitive for production deployment. Our \textbf{Expert Distillation} bootstraps from teacher priors, achieving 63.6\% regret reduction from day one without exploration overhead.

\textbf{Static leaderboards} (LMSYS~\cite{zheng2023judging}, HELM~\cite{liang2022holistic}) provide global rankings but ignore cost and average across all users. We build a personalized, cost-aware ranking optimized for each deployment's utility function.

The key differentiator is \textbf{zero-overhead scalability}: FrugalGPT/RouteLLM require $O(N)$ profiling to add models; we use benchmarks only as optional ``safety rails'' derived from public metadata, not as training data. New models are verified \emph{during} deployment via online exploration, enabling drop-in integration for the rapidly evolving LLM landscape.
