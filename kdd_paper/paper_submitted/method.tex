\section{Density-Based Warm-Start Framework}
\label{sec:method}

\subsection{Problem Definition}
\label{sec:problem}

Given query $q$ and model pool $\mathcal{M} = \{m_1, \ldots, m_M\}$, select:
\begin{equation}
m^* = \argmax_{m \in \mathcal{M}} \left[ \hat{Q}(q, m) - \lambdacost \cdot C_m - \lambdalat \cdot L_m \right]
\label{eq:utility}
\end{equation}
where $\hat{Q}(q, m)$ is predicted quality, $C_m$ is cost, $L_m$ is latency, and $\lambdacost, \lambdalat$ are trade-off weights. The challenge: $\hat{Q}$ is unknown and must be learned, but naive online learning requires thousands of costly queries.

\subsection{System Architecture}
\label{sec:architecture}

Our system has two paths: (1) \textbf{Hot Path}: millisecond-scale LinUCB selection; (2) \textbf{Cold Path}: asynchronous quality assessment for learning.

\paragraph{Context Embedding.} Each query maps to $\mathbf{x} = \text{Embed}(q) \in \mathbb{R}^{384}$ using a sentence transformer (all-MiniLM-L6-v2), encoding semantic position in ``meaning space.''

\paragraph{Disjoint LinUCB.} Each model $m$ maintains: $\mathbf{A}_m \in \mathbb{R}^{d \times d}$ (covariance) and $\mathbf{b}_m \in \mathbb{R}^{d}$ (reward accumulator). Predicted quality with exploration bonus:
\begin{equation}
\hat{Q}(q, m) = \underbrace{\boldsymbol{\theta}_m^\top \mathbf{x}}_{\text{exploitation}} + \underbrace{\alpha \sqrt{\mathbf{x}^\top \mathbf{A}_m^{-1} \mathbf{x}}}_{\text{exploration}}
\label{eq:ucb}
\end{equation}
where $\boldsymbol{\theta}_m = \mathbf{A}_m^{-1} \mathbf{b}_m$ encodes model $m$'s learned strengths.

\paragraph{Real-Time Learning.} On feedback $(m, \mathbf{x}, r)$, rank-one updates in $O(d^2)$:
\begin{align}
\mathbf{A}_m &\leftarrow \mathbf{A}_m + \mathbf{x}\mathbf{x}^\top, \quad
\mathbf{b}_m \leftarrow \mathbf{b}_m + r \cdot \mathbf{x}
\label{eq:update}
\end{align}

\subsection{Why Contextual Bandits?}
\label{sec:pivot}

Static classifiers~\cite{ong2024routellm} freeze after training. We use bandits for: (1) \textbf{Distribution Drift}---GPT-4o's capabilities shift monthly; our bandit adapts online. (2) \textbf{Domain Specificity}---discover \emph{local} specialists invisible to global benchmarks. (3) \textbf{Principled Exploration}---LinUCB explores only when uncertain, mathematically optimal under linear assumptions~\cite{abbasi2011improved}.

\subsection{Expert Distillation}
\label{sec:distillation}

The cold-start problem: 81 models $\times$ 384 dimensions requires thousands of queries. We solve this via \textbf{Expert Distillation} using GPT-4o as teacher.

\paragraph{Archetype Grid.} Sample 50K prompts from LMSYS Chatbot Arena~\cite{zheng2023judging}, embed with sentence transformer, cluster via K-Means ($K=497$), and select centroid representatives. This yields 497 ``golden prompts'' spanning the task distribution.

\paragraph{Dense Evaluation.} For each (model, archetype) pair, generate responses via OpenRouter and grade with GPT-4o (normalized $[0,1]$). The oracle achieves $>$80\% agreement with human preferences.

\paragraph{Prior Fitting.} Train the bandit by simulating oracle decisions: for each archetype with embedding $\mathbf{x}$ and optimal model $m^*$, apply rank-one updates. Repeat for 5 epochs.

\paragraph{Prior Strength ($\lambdaboost$).} Scale priors: $\mathbf{A}_m \leftarrow \lambdaboost \cdot \mathbf{A}_m$. With $\lambdaboost=50$ (default), the exploration term shrinks by $1/\sqrt{50}$, strongly favoring exploitation. This is valid because the prior genuinely encodes expert knowledge.

\paragraph{Specialist Discovery.} The router discovers specialists \emph{beyond} the teacher. Nova-Lite achieves $\|\boldsymbol{\theta}\|=3.66$ vs.\ GPT-4o's 1.66, with near-zero cosine similarity---proving it captures a distinct niche (Figure~\ref{fig:specialist_landscape}).

\subsection{Bandit-Guided Cascade}
\label{sec:hybrid}

For maximum accuracy, we introduce a \textbf{Bandit-Guided Cascade}. FrugalGPT~\cite{chen2023frugalgpt} achieves high accuracy via cascading but is limited to 2--3 models with $O(N)$ latency. Our hybrid uses the bandit as a \textbf{dynamic head}:

\begin{equation}
\text{Route}(q) = 
\begin{cases}
\text{SingleShot}(m^*) & \text{if } \hat{Q}(q, m^*) > \tau \\
\text{Cascade}(m^* \to \text{GPT-4o}) & \text{otherwise}
\end{cases}
\label{eq:hybrid}
\end{equation}
