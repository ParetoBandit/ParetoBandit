# BanditGPT Prior Data

This directory contains pre-computed prior matrices and reference data required by the BanditRouter at runtime.

## Contents

### Prior Covariance Matrices

- **`priors_meta_clusters.npz`** (880K) - Cluster-based priors
  - Contains: `cov_matrix`, `sum_vec`, `cluster_sums`, `global_sum`
  - Used by: Default BanditRouter configuration
  - Features: 387-dimensional (384 embedding + 3 cluster features)

- **`priors_meta_pca.npz`** (54K) - PCA-reduced priors (Recommended)
  - Contains: `cov_matrix`, `sum_vec`, `cluster_sums`, `global_sum`
  - Used by: Hybrid PCA architecture
  - Features: 45-dimensional (32 PCA + 8 handcrafted + 5 cluster)

- **`priors_meta_large.npz`** (578K) - Full embedding priors
  - Contains: `cov_matrix`, `sum_vec`
  - Used by: Legacy configuration
  - Features: 384-dimensional (raw embeddings)

### Dimensionality Reduction

- **`pca_32.joblib`** (51K) - Fitted PCA model
  - Transforms: 384D MiniLM embeddings → 32D
  - Trained on: ~25K LMSYS prompts (excluding train/test sets)
  - Explained variance: ~85%

### Reference Data

- **`golden_prompts.jsonl`** (19K) - Cluster representative prompts
  - Contains: One representative prompt per cluster (100 clusters)
  - Used by: ClusterDetector for nearest cluster assignment
  - Format: `{"prompt": "...", "cluster_id": N, "similarity": X.XX}`

## Usage

### Loading Priors in BanditRouter

```python
from banditgpt import BanditRouter

# Option 1: Cluster-based priors (default)
router = BanditRouter.create(
    priors_path="banditgpt/priors/priors_meta_clusters.npz"
)

# Option 2: PCA-based priors (recommended for production)
router = BanditRouter.create(
    priors_path="banditgpt/priors/priors_meta_pca.npz",
    use_pca=True,
    pca_path="banditgpt/priors/pca_32.joblib"
)
```

### Loading ClusterDetector

```python
from banditgpt.cluster_detector import ClusterDetector

detector = ClusterDetector(
    golden_prompts_path="banditgpt/priors/golden_prompts.jsonl"
)
```

## File Generation

These files are generated by:

1. **Prior matrices**: `banditgpt/data/scripts/generate_cluster_priors.py`
2. **PCA model**: `banditgpt/data/scripts/pca_manager.py`
3. **Golden prompts**: `banditgpt/data/scripts/find_golden_prompts.py`

To regenerate:

```bash
cd banditgpt/data/scripts
python generate_cluster_priors.py  # Generates priors_meta_clusters.npz
python -c "from pca_manager import train_pca_pipeline; train_pca_pipeline(...)"
python find_golden_prompts.py  # Generates golden_prompts.jsonl
```
