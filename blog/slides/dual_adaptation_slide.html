Dual Adaptation Architecture

How ParetoBandit self-corrects through cost and quality perturbations
Reward Shift
Model quality changes post-deployment
→ Model degradation → Catastrophic failure → New model added
Cost Shift
Provider pricing changes overnight
→ 50–80% price cuts → New tier introduced → Rate limit changes
γ
Geometric Forgetting
Adapts reward estimates

Detect: Down-weight stale evidence via γt exponential decay
2
Adapt: UCB scores reflect current model quality, not historical average
3

Independent & complementary
λt
Online BudgetPacer
Adapts cost-quality tradeoff
1
Monitor: EMA of realized $/request vs. operator’s target rate
2
Adjust: λt+1 = [λt + η(cost_ema − target)]+ every request
3
Enforce: Higher λ penalises expensive arms; lower λ unlocks them
⚠ Without forgetting (γ = 1)
λt alone cannot fix stale reward estimates. The bandit keeps selecting a degraded model — catastrophic inertia. This is the failure mode of all existing bandit-based LLM routers.
Quality Maintained
Router discovers best models within ~200 rounds of any perturbation
Exp 3: steady-state in ~200 steps
Budget Enforced
$/request rate target held across arbitrary cost regime changes
Exp 2: <3% overshoot, self-corrects

Geometric forgetting handles reward non-stationarity. The online dual variable handles cost non-stationarity. Together they provide closed-loop adaptation to arbitrary perturbations — something no existing LLM router offers.
