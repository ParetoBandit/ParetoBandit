\subsection{Configuration Details}
\label{app:config}

This section documents all configurable parameters of the banditGPT library router
(\texttt{src/bandit\_gpt/router.py}) and the specific values used in each experiment.
Library defaults are listed alongside experiment values to enable both reproduction
of paper results and deployment with the production library.

\paragraph{Implementation Notes.}
\begin{enumerate}[leftmargin=*,noitemsep]
    \item \textbf{Initialization-Only Regularization:} The default
    \texttt{init\_lambda}$=1.0$, \texttt{update\_lambda}$=0.0$ pattern provides
    cold-start stability via $A_0 = I$ while allowing $O(d^2)$ Sherman--Morrison
    updates at runtime (4$\times$ faster than $O(d^3)$ with runtime regularization).

    \item \textbf{Two-Level Cost Mechanism:} The library supports cost awareness at
    two levels: (a) \texttt{cost\_penalty} in each LinUCB expert penalizes arm costs
    within the UCB score; (b) \texttt{cost\_weight} in CorrallingRouter transforms
    the reward signal before it reaches both the meta-learner and experts.
    These should not be used simultaneously to avoid double-counting.

    \item \textbf{Loss Decay (Non-Standard Corralling):} The \texttt{loss\_decay}
    parameter modifies the standard Exp4 algorithm by exponentially discounting
    past cumulative losses at the meta level. This prevents weight collapse under
    distribution shift but means the standard $O(\sqrt{T \ln K})$ regret bound
    applies only approximately. The theoretical analysis in Appendix~\ref{appendix:mathematical_foundations}
    assumes standard Exp4 ($\texttt{loss\_decay}=1.0$); the experiments in this paper
    also use $\texttt{loss\_decay}=1.0$.
\end{enumerate}

\subsubsection{Cost Penalty Sweep (Figure~4)}

The Pareto frontier sweeps 10 cost penalty values:
\begin{equation*}
\lambda \in \{0.0,\; 0.01,\; 0.02,\; 0.05,\; 0.1,\; 0.2,\; 0.5,\; 1.0,\; 2.0,\; 5.0\}
\end{equation*}
with 20 independent seeds per $\lambda$ value (200 total runs).
The RouteLLM baseline uses 28 threshold values $\tau \in [0.0, 1.0]$.
