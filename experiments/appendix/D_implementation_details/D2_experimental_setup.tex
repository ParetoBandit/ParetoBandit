\begin{itemize}[leftmargin=*,noitemsep]
    \item \textbf{CPU:} Apple M2 (single core used)
    \item \textbf{RAM:} 16 GB
    \item \textbf{GPU:} None required (all computation is CPU-based)

\end{itemize}

\subsubsection{Evaluation Protocol}

\paragraph{Zero-Leakage Design.}
All experiments enforce strict separation between training and evaluation:
\begin{enumerate}[leftmargin=*,noitemsep]
    \item \textbf{PCA and priors} are trained exclusively on warmup data (80K RouteLLM battles for $K{=}2$; prior-training split for $K{>}2$).
    \item \textbf{Online learning} (Figure~4) uses the development split (1,121 prompts); Figures~5 and 7 use the online-learning portion of the three-way split (${\sim}$533 prompts).
    \item \textbf{Evaluation} uses the holdout split (750 prompts), never seen during training or prior construction.
    \item \textbf{Three-way split integrity} ($K{>}2$): Pairwise disjointness of prior-training, online-learning, and holdout sets is verified programmatically before each experiment.
    \item \textbf{Normalization statistics} (mean, std for cost penalties) are computed on the training set and frozen during evaluation.
    \item \textbf{Deduplication}: 243 incidental overlaps between warmup and evaluation data were removed (0.24\% of warmup set).
\end{enumerate}

\paragraph{Metrics.}
We report two primary metrics:
\begin{itemize}[leftmargin=*,noitemsep]
    \item \textbf{Average Reward:} Mean win rate across holdout prompts, $\bar{R} = \frac{1}{T}\sum_{t=1}^{T} r_t$ where $r_t \in \{0,\, 0.5,\, 1\}$ encodes a loss, tie, or win in the pairwise comparison (see Appendix~\ref{appendix:reward_signal}).
    \item \textbf{Average Cost:} Mean per-request API cost, $\bar{C} = \frac{1}{T}\sum_{t=1}^{T} c_{a_t}$ where $c_{a_t}$ is the cost of the model selected at step $t$.
\end{itemize}

\paragraph{Statistical Reporting.}
All multi-seed results report mean $\pm$ standard deviation.
Significance tests use Wilcoxon signed-rank (paired, non-parametric) with Benjamini-Hochberg FDR correction where multiple comparisons are made.

\paragraph{Reproducibility.}
All experiment scripts accept a \texttt{--seed} argument for deterministic replication.
Code, data, and pre-computed PCA/prior artifacts are available at: \url{https://github.com/atabernermiller/banditGPT}.
