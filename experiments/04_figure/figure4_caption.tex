    \centering
    \includegraphics[width=\linewidth]{figures/figure4_k10.png}
    \caption{Cost--quality Pareto frontier for a 10-model portfolio.
    Bold lines show the \emph{dev-selected deployable frontier}: the dev set is
    split 80/20 into train/val; both methods train on dev-train, and the Pareto
    hull is built from $(c_{\text{dev-val}}, r_{\text{dev-val}})$.
    Plotted points are the holdout performance of those dev-optimal
    hyperparameters (no holdout or training data leakage in selection).
    Shaded regions show the oracle upper-bound envelope (holdout-selected;
    not deployable).
    BanditGPT (Corralling + 43-model warmup priors, $\alpha{=}0.5$) is swept over
    $\lambda \in [0,\,1]$ (33 values); error bars show 95\% $t$-CIs across 20 seeds.
    Frozen evaluation uses greedy exploitation ($\alpha{=}0$).
    Training uses the dev-train portion of the online-learn pool
    (${\sim}426$ prompts, 80\% of $n{=}533$) from the three-way split;
    evaluation on the canonical holdout set ($n{=}750$).
    Note: the 10-armed contextual bandit adapts from fewer than 43
    interactions per arm on average.
    %
    Each non-frontier baseline appears as a single point because it lacks
    a mechanism to continuously trade cost for quality:
    \emph{Oracle}---per-prompt clairvoyant $\arg\max_m r(m,x)$ ($0.968$,
    \$0.0014/req); defines one unique optimal assignment;
    \emph{Best static}---always route to GPT-4.1 ($0.910$, \$0.0034/req);
    locked to one model's price;
    \emph{Best-static+noise}---$\varepsilon$-greedy perturbation of training-set
    best model (Claude-Sonnet-4, $0.886$, \$0.0059/req); the most expensive
    baseline without the highest reward;
    \emph{UCB1}---non-contextual online bandit, converges to a single arm
    (Gemini-2.5-Flash, $0.886$, \$0.0030/req); without prompt features, collapses
    to best-arm selection;
    \emph{Random}---uniform model selection ($0.823$, \$0.0026/req).
    \emph{Tabula rasa}---BanditGPT without priors or Corralling (plain LinUCB,
    $\alpha\!: 0.25 {\to} 0.01$).
    BanditGPT is the only method that produces a full Pareto frontier: the cost
    penalty~$\lambda$ and contextual features jointly enable per-prompt routing
    that varies cost with prompt difficulty.
    %
    Primary test: paired bootstrap 95\% CI for dev-selected Pareto AUC difference
    (1{,}000 holdout resamples; dev indices fixed before bootstrapping).
    BanditGPT dominates across the full cost range (AUC $0.652$ vs.\ tabula rasa
    $0.332$; advantage $+0.320$, 95\% CI $[+0.309,\, +0.331]$, $p{=}0.0$).
    %
    All quality values are ground-truth multi-judge scores via \texttt{extract\_reward}
    (mean of vote $\times$ confidence).
    Cost model uses fixed per-request prices (100 input + 400 output tokens).}
    \label{fig:pareto_k10}
\end{figure}
