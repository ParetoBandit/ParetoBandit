\begin{figure}[htbp]
    \centering
    \includegraphics[width=\linewidth]{../experiments/03_figure/results/figure3_warmup_ablation.pdf}
    \caption{Cold-start prior value for the $K{=}2$ portfolio
    (\texttt{Llama-3.1-8B} vs.\ \texttt{Gemini-2.5-Pro}) at
    cost penalty $\lambda_c{=}0.15$, averaged over 20~seeds
    ($\pm 1$~SE shaded).
    Both conditions are deployed \textbf{from cold start} on the
    held-out test split ($n{=}1{,}824$) with \textbf{no pre-training
    phase}---the router sees its first prompt at $t{=}1$.
    Both use the same exploration rate ($\alpha{=}0.5$); the only
    difference is whether the bandit starts with warmup priors.
    %
    \textbf{(a)}~Cumulative regret
    $\sum_{t=1}^{T}[\max_a \mu_a(x_t) - \mu_{a_t}(x_t)]$
    from the first prompt.
    BanditGPT (warm priors, solid blue) accumulates
    $69.3 \pm 0.5$ regret versus
    $86.2 \pm 1.5$ for Tabula Rasa (no priors, dashed gray),
    a \textbf{19.6\% reduction}.
    The gap opens from prompt~1 and widens monotonically:
    within the first 100~prompts, warmup priors reduce
    regret by 61\% ($3.0$ vs.\ $7.7$).
    %
    \textbf{(b)}~Windowed average reward (window${=}100$).
    BanditGPT starts near $0.92$ and maintains high reward
    throughout, while Tabula Rasa starts below $0.86$ with
    wide seed-level variance and requires ${\sim}500$~prompts
    to converge.
    %
    Warmup priors are built offline from the training split
    (full-information ridge regression)---the same data available
    to supervised baselines (Figure~\ref{fig:pareto_k2}).
    The test split was not used for prior construction or
    hyperparameter selection.}
    \label{fig:warmup_ablation_k2}
\end{figure}
