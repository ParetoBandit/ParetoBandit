    Frozen holdout evaluation with greedy exploitation ($\alpha{=}0$).
    Error bars show 95\% $t$-CIs across 20 seeds.

    The crossover annotation marks the earliest step from which BanditGPT's lower CI bound
    \emph{persistently} exceeds RouteLLM's peak ($0.788$) for all subsequent checkpoints.

    via \texttt{extract\_reward}), not proxy predictions.
