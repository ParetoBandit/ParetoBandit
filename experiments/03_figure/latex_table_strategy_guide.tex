\textbf{Regret} column: at $\alpha{=}0$ (best case for prior-dependent strategies).
\textbf{Range} column: regret across the good-to-moderate corruption

\textbf{Note:} Warmup-only (52--67) is omitted as it is never optimal at
any corruption level.

\textbf{Breakeven rule:}
Corralling has better expected regret than tabula rasa if you believe
there is $\geq 57\%$ probability that priors are useful ($\alpha \leq 0.4$).

\textbf{Adaptive workflow:}
Start with Corralling (library default) and monitor the first 50--100
prompts.  If warmup expert accuracy falls below random chance, switch to
tabula rasa to cap downside risk.
