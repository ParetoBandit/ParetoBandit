\subsection{Practical Deployment Recommendations}
\label{sec:practical}

The prior degradation sweep (\S\ref{sec:metalearning_cost}) establishes
that Corralling dominates both alternatives for good-to-moderate priors
($\alpha \leq 0.5$) but becomes unstable under adversarial conditions
($\alpha \geq 0.6$).
This section translates those findings into deployment guidance.

% ----------------------------------------------------------------------------
% Recommendation 1: Default is Corralling
% ----------------------------------------------------------------------------
\paragraph{Default: Corralling with Hybrid LinUCB.}
The library ships Corralling as the default strategy.  This is the
recommended starting point for all deployments because:

\begin{enumerate}[nosep]
    \item \textbf{Dominant when priors are useful:}
    Corralling achieves 29--39\% lower regret than both warmup-only and
    tabula rasa when $\alpha \leq 0.5$ (regret 32--38 vs.\ 52+).
    \item \textbf{Complementary alpha schedules:}
    The warmup expert (constant $\alpha{=}2.0$) provides informed early
    selections; the tabula rasa expert (decaying $\alpha{=}1.0 \to 0.01$)
    converges to the best policy.  The meta-learner exploits both.
    \item \textbf{53\% breakeven threshold:}
    Corralling has better expected regret than tabula rasa if there is
    $\geq 53\%$ probability that priors are useful.  Most deployments
    easily clear this bar.
\end{enumerate}

```python
from bandit_gpt import BanditRouter

router = BanditRouter.create(
    models=["mixtral-8x7b", "gpt-4-turbo"],
    warmup_priors=priors,
)

selection = router.route(prompt="Explain quantum computing")
# ... get reward ...
router.process_feedback(selection.selection_token, reward=1.0)
```

% ----------------------------------------------------------------------------
% When to switch to Tabula Rasa
% ----------------------------------------------------------------------------
\paragraph{When to Switch to Tabula Rasa.}
Use tabula rasa in three scenarios:

\begin{enumerate}[nosep]
    \item \textbf{Cold start (no priors):}
    No offline data available at all.  Tabula rasa's regret (${\sim}52$)
    is the natural starting point.
    \item \textbf{Confirmed adversarial priors:}
    Validation on 100--200 deployment samples shows prior accuracy
    below 50\%.
    \item \textbf{Zero tolerance for instability:}
    High-stakes domains (healthcare, finance) where Corralling's
    variance at adversarial corruption ($\sigma{\approx}23$) is
    unacceptable, even though the expected case favors Corralling.
\end{enumerate}

```python
router = BanditRouter.create(
    models=["mixtral-8x7b", "gpt-4-turbo"],
    use_corralling=False,
)
```

% ----------------------------------------------------------------------------
% Warmup-only is not recommended
% ----------------------------------------------------------------------------
\paragraph{Warmup-Only is Not Recommended.}
The prior degradation sweep shows that warmup-only is \emph{never} the
best strategy at any corruption level.  Corralling dominates it across
the entire spectrum because the warmup expert's constant exploration
($\alpha{=}2.0$) continues second-guessing correct beliefs, while
Corralling shifts weight to the converging tabula rasa expert.
Users who previously used warmup-only should migrate to Corralling for
strictly better performance.

% ----------------------------------------------------------------------------
% Monitoring and escape hatches
% ----------------------------------------------------------------------------
\paragraph{Runtime Monitoring.}
The library provides mechanisms to detect and escape the adversarial
regime:

\begin{itemize}[nosep]
    \item \textbf{$\gamma$-floor mixing ($\gamma{=}0.05$):}
    Ensures the tabula rasa expert always receives $\geq 5\%$ of traffic,
    maintaining its ability to learn even when the meta-learner favors
    the warmup expert.
    \item \textbf{Loss decay:}
    Stale expert losses are forgotten, preventing early mistakes from
    permanently anchoring the meta-learner.
    \item \textbf{Early monitoring:}
    Track warmup expert accuracy over the first 50--100 prompts.
    If it falls below random chance, switch to tabula rasa to cap
    downside risk.
\end{itemize}

This enables a \emph{start with Corralling, monitor, adjust} workflow:
deploy with the default, then switch to tabula rasa only if runtime
signals indicate adversarial prior quality.

% ----------------------------------------------------------------------------
% Exploration and Gamma
% ----------------------------------------------------------------------------
\paragraph{Exploration and Mixing Defaults.}
Warmup expert $\alpha{=}2.0$ (constant) is validated by hyperparameter
sensitivity analysis (Appendix~\ref{app:hp_sensitivity}); tabula rasa
$\alpha$ decays from 1.0 to 0.01.  The mixing parameter $\gamma{=}0.05$
has negligible impact on regret (total range ${<}1.0$ across tested
values) and requires no tuning.
