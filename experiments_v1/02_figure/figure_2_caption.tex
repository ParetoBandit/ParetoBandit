% Hierarchical coordinator-expert system for adaptive model routing

\begin{figure}[t]
    \centering
    \includegraphics[width=\textwidth]{experiments_v1/02_figure/results/corralled_architecture.pdf}
    \caption{%
        \textbf{Corralled Architecture: Hierarchical Coordination of Warmup and Tabula Rasa Experts.}
        The banditGPT system implements a \textbf{coordinator-expert hierarchy} where a meta-controller dynamically allocates trust between two complementary routing strategies.
        %
        \textbf{(Top)} The \textit{Coordinator Layer} maintains a trust distribution $\pi_t$ over experts, tracks cumulative regret, and manages the exploration budget.
        At each timestep $t$, the coordinator samples an expert proportionally to its trust weight.
        %
        \textbf{(Middle)} The \textit{Expert Layer} consists of two LinUCB bandit instances:
        (1)~\textit{Warmup Expert} initializes with semantic priors from latent space analysis (Figure~1), enabling fast cold-start convergence.
        (2)~\textit{Tabula Rasa Expert} learns purely from online feedback without priors, ensuring unbiased adaptation to deployment distribution.
        The coordinator samples an expert based on $\pi_t$, which then recommends an action that is executed.
        %
        \textbf{(Bottom)} The \textit{Feedback Phase} computes importance-weighted losses and updates both layers:
        The system calculates the loss $\ell = \frac{1-r}{\pi_i}$ for the selected expert, updates the coordinator's cumulative losses $L[i] \leftarrow L[i] + \ell$, renormalizes the trust distribution $\pi \leftarrow \text{normalize}(\exp(-\eta L))$, and updates the expert's LinUCB parameters $(A, b)$ using the observed context-action-reward tuple.
        %
        This design provides \textbf{three key guarantees}:
        (1)~\textbf{Robustness}---system remains effective even if Warmup priors are misspecified, as Tabula Rasa corrects for distribution shift.
        (2)~\textbf{Fast Convergence}---Warmup expert accelerates early learning when priors are helpful.
        (3)~\textbf{Provable Regret}---corralling ensures $O(\sqrt{T})$ regret relative to the best expert in hindsight, unlike heuristic ensembles.
        %
        Arrows indicate information flow: dashed lines represent recommendations (expert→coordinator), solid lines represent selections (coordinator→expert), and bold lines represent feedback (environment→both).
    }
    \label{fig:corralled_architecture}
\end{figure}
