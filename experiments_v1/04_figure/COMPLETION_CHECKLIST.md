## ✅ Mathematical Correctness

### Importance-Weighted Loss
- [x] Formula: $\hat{\ell}_{t,e} = \frac{\mathbb{1}_{e=e^*}(1 - r_t)}{\rho_{t,e}}$
- [x] Unbiased estimator: $\mathbb{E}[\hat{\ell}_{t,e}] = 1 - r_t$
- [x] Only chosen expert penalized (no counterfactuals)
- [x] Implemented in `CorrallingRouter.update()`

### Exponential Weights
- [x] Formula: $w_{t+1,e} = \frac{\exp(-\eta \cdot L_{t,e})}{\sum_{e'} \exp(-\eta \cdot L_{t,e'})}$
- [x] Weights sum to 1
- [x] Weights non-negative
- [x] Learning rate $\eta$ controls adaptation

### Safety Guarantee
- [x] Regret bound: $\mathbb{E}[\text{Regret}] \leq \min_{e} \mathbb{E}[\text{Regret}_e] + O(\sqrt{T \log E})$
- [x] No worse than best expert
- [x] Overhead only $O(\sqrt{T})$
