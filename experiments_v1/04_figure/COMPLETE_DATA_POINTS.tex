\bottomrule

\textbf{The ``Stupidity Tax'' Phenomenon:}

This dataset exhibits a rare but scientifically significant pattern: the expensive model (GPT-4) performs \textit{worse} on average than the cheap model (Mistral). This creates a ``Stupidity Tax'' where users pay $43\times$ more to \textit{decrease} quality by $1.3\%$.

This inversion occurs because:
\begin{itemize}
    \item \textbf{Domain Specialization:} Mistral excels on the $94.2\%$ of routine, domain-specific prompts
    \item \textbf{Overengineering Penalty:} GPT-4 introduces unnecessary latency and generalization bias
    \item \textbf{Sparse Hard Cluster:} Only $\sim 6\%$ of prompts truly benefit from GPT-4's reasoning
\end{itemize}

The Oracle demonstrates that \textit{perfect routing} can extract value from the expensive model (achieving 0.953 at only $6.6\times$ cost), but this requires identifying the exact prompts where GPT-4 outperforms---a task that static routers fail at catastrophically.
