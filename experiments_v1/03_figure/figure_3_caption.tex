    \caption{%
        \textbf{Architecture: Corralling-Based Adaptive Router.}
        The coordinator manages two LinUCB experts via Exp4 meta-learning
        ($\eta{=}\sqrt{\ln K/T}$, $\gamma{=}0.05$).
        Expert~1 (Warmup) initialises with semantic priors; Expert~2
        (Tabula Rasa) learns from scratch.
        At each request, the coordinator samples an expert with
        probability $P_t = (1{-}\gamma)\,w_t + \gamma/K$ and updates
        weights via importance-weighted loss
        $\hat{\ell}_t = (1{-}r_t)/P_t$.
        Figure~\ref{fig:prior_degradation} shows that this architecture
        correctly adapts to prior quality across the full spectrum---from
        60\% overhead with strong priors to outperforming warmup-only
        when priors degrade.
        Hyperparameter ablations in Appendix~\ref{app:ablations}.
    }
