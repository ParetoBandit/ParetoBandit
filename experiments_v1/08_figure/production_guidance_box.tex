\textbf{TL;DR:} Use default \texttt{n\_effective = 5.0} and enable Corralling. System robustness comes from \textit{adaptive expert selection}, not hyperparameter tuning.

\vspace{0.2cm}
\hrule
\vspace{0.2cm}

\textbf{What We Learned:}
\begin{itemize}[leftmargin=*, itemsep=1pt, topsep=2pt]
    \item \texttt{n\_effective} only matters \textbf{33\% of time} (when Corralling uses warmup expert)
    \item \textbf{67\% of time}, Corralling abandons semantic transfer (priors mismatch data)
    \item Overall production impact: $\sim$\textbf{1.5\%} (0.33 $\times$ 4.6\%)
    \item Strong priors (\texttt{n\_effective $>$ 10}) can \textit{underperform cold start} by 3.9\%
\end{itemize}

\vspace{0.2cm}
\hrule
\vspace{0.2cm}

\textbf{Recommended Configuration:}
\begin{verbatim}
use_corralling = True          # Enable adaptive switching
n_effective_default = 5.0      # Mid-range value
\end{verbatim}

\vspace{0.2cm}
\hrule
\vspace{0.2cm}

\textbf{What to Monitor} (not hyperparameters):
\begin{enumerate}[leftmargin=*, itemsep=1pt, topsep=2pt]
    \item \textbf{Expert selection frequency}: Expect 30-70\% warmup expert usage
    \item \textbf{Performance by regime}: Track reward when warmup vs tabula rasa active
    \item \textbf{Red flag}: 100\% either expert for >1000 steps indicates prior mismatch
\end{enumerate}

\vspace{0.2cm}
\hrule
\vspace{0.2cm}

\textbf{Key Insight:} Corralling provides robustness by \textit{selectively applying} semantic transfer only when priors match production traffic, rather than universally relying on it. This meta-learning approach eliminates the need for manual prior validation or hyperparameter optimization.

\end{tcolorbox}
