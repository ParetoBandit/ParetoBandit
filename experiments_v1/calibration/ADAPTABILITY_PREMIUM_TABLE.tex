% For paper narrative: Key insight box
\begin{tcolorbox}[colback=blue!5!white,colframe=blue!75!black,title=Key Insight: The Adaptability Premium]
The +314\% cost gap between BanditGPT and the theoretical oracle is \textbf{not a failure}—it is the \textbf{Adaptability Premium}. This premium buys three production-critical capabilities that the oracle lacks:

\begin{enumerate}
    \item \textbf{Real-time streaming} vs batch processing (cannot wait for all prompts)
    \item \textbf{Model substitution robustness} vs brittle thresholds (handles GPT-4 → GPT-5 updates)
    \item \textbf{Zero upfront labeling} vs perfect knowledge (no ground-truth rewards required)
\end{enumerate}

\textbf{The "Smoking Gun":} BanditGPT achieves \textbf{70\% cost savings} vs the naive Always Strong baseline while maintaining \textbf{86\% of oracle quality}, despite deploying on a model (GPT-4o) it wasn't trained on (GPT-4-turbo). 

In production settings where the oracle is \emph{infeasible}, BanditGPT represents the Pareto-optimal trade-off between cost, quality, and adaptability.
\end{tcolorbox}
