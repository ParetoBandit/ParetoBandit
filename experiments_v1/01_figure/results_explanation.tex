\subsection{Forensic Analysis of Task Difficulty}
\label{sec:semantic_structure}

Before presenting our routing algorithm, we first establish that task difficulty in the LMSYS holdout set is not merely a function of reasoning complexity, but also of model alignment. 
Figure~\ref{fig:lmsys_holdout_structure} visualizes 1,871 prompts from the LMSYS dev and holdout sets projected onto the first two principal components of a 32-component PCA model. 
This projection reveals a \textbf{Bimodal Semantic Structure} that fundamentally challenges the assumption that "harder" tasks always require "stronger" models.

\paragraph{The Alignment Tax Discovery.} 
Contrary to the expectation that flagship models (GPT-4-Turbo) strictly dominate mid-tier models (Mixtral-8x7B), our semantic analysis uncovers a specific failure mode we term the \emph{Alignment Tax}. 
As illustrated in the High PC1 cluster (Red, 17.6\% of prompts), there exists a semantic region dominated by strict constraints---specifically, "text completion" templates requiring exact formatting without conversational filler.

\begin{itemize}[noitemsep,topsep=2pt]
    \item \textbf{Natural Language Core (Low PC1, 82.4\%):} This region contains standard open-ended conversational queries. Here, the flagship model retains its expected advantage ($\Delta = +0.13$), justifying its higher cost for nuances in reasoning and helpfulness.
    
    \item \textbf{Strict Constraint Zone (High PC1, 17.6\%):} This cluster isolates tasks with rigid formatting requirements. In this region, the reward gap inverts ($\Delta = -0.68$), meaning the cheaper model (Mixtral) significantly outperforms the flagship. 
    Qualitative analysis suggests this is an artifact of RLHF: flagship models are heavily aligned to be "helpful chat assistants," often refusing to act as raw text completion engines or injecting unwanted conversational preambles (e.g., "Sure, here is the completion...") that violate strict negative constraints.
\end{itemize}

\paragraph{Implications for Routing.}
This inversion provides the strongest empirical justification for adaptive routing over static "complexity" heuristics. 
A static router based on "difficulty" might assume that strict, complex constraints require the strongest model. 
However, \texttt{banditGPT} learns the \emph{empirical} truth: the strongest model is structurally maladapted to these tasks.
By identifying this "Alignment Tax" zone, the router achieves cost reduction not just by offloading easy tasks, but by protecting the user from the flagship model's own alignment biases on strict tasks.
