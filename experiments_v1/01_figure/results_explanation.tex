\subsection{Model Preference Heterogeneity Analysis}
\label{sec:semantic_structure}

Before presenting our routing algorithm, we first establish that prompt structure correlates with differential model performance in the LMSYS held-out set.
Figure~\ref{fig:lmsys_holdout_structure} visualizes 750 held-out prompts projected onto the first principal component of a domain-adapted PCA model (trained on 80K routing prompt embeddings, unsupervised).
This projection reveals \textbf{model preference heterogeneity}: a minority of prompts where the cheaper model significantly outperforms the frontier.

\paragraph{Model Preference Heterogeneity.} 
Contrary to the expectation that frontier models (GPT-4-Turbo) strictly dominate cheaper alternatives (Mixtral-8x7B), our analysis uncovers a subset of prompts where model preference inverts.
Using a silhouette-optimal threshold ($\text{PC1} = 0.222$, selected without reference to reward labels), we identify two clusters:

\begin{itemize}[noitemsep,topsep=2pt]
    \item \textbf{Low PC1 Cluster (80.8\%, $n=606$):} Diverse conversational prompts where the frontier model retains a moderate advantage ($\Delta = +0.121$, 95\% CI: $[+0.088, +0.153]$), consistent with its superior instruction following and world knowledge.
    
    \item \textbf{High PC1 Cluster (19.2\%, $n=144$):} Prompts with strict formatting constraints where the reward gap inverts ($\Delta = -0.563$, 95\% CI: $[-0.661, -0.464]$), meaning the cheaper model (Mixtral) significantly outperforms the frontier.
    Qualitative inspection reveals this cluster is dominated by instruction-following templates, binary classification tasks, structured output requirements, and explicit negative constraints.
    We observe that the frontier model's conversational tendencies (e.g., adding preambles, explaining reasoning) correlate with violations of strict formatting requirements, while the open-weights model adheres more closely to template structure.
\end{itemize}

\paragraph{Statistical Validation.}
We validate the cluster distinction through multiple statistical tests. The difference between clusters is highly significant (Mann-Whitney $U$-test: $p < 0.0001$), with a large effect size (Cohen's $d = 1.53$). 
The 95\% confidence intervals for the two clusters do not overlap, confirming that the semantic structure corresponds to genuine differences in model performance.

\paragraph{PCA Robustness.}
To confirm this finding is not an artifact of domain-adapted PCA, we repeat the analysis with PCA trained on 100K generic web text samples (C4 corpus). The effect persists ($p < 0.0001$, Cohen's $d = 0.33$), confirming the structure exists independently of PCA provenance. The domain-adapted PCA concentrates routing-relevant variation more efficiently ($d = 1.53$ vs.\ $0.33$), consistent with its training on routing-relevant prompts.

\paragraph{Methodological Notes.}
\begin{itemize}[noitemsep,topsep=2pt]
    \item \textbf{Data:} Held-out test set only ($N=750$). Dev set excluded.
    \item \textbf{PCA:} Domain-adapted, trained on 80K routing prompts (unsupervised---no reward labels).
    \item \textbf{Threshold:} Silhouette-optimal ($\text{PC1} = 0.222$), selected without reward labels.
    \item \textbf{Rewards:} LMSYS Chatbot Arena human preference evaluations.
    \item \textbf{High-D structure:} Weak in 384D (silhouette $= 0.057$); PC1 captures moderate signal ($\rho^2 = 0.156$).
    \item \textbf{Cluster diversity:} High PC1 is homogeneous (diversity $= 0.355$), consistent with a coherent semantic category.
    \item \textbf{Causal mechanism:} Not ablated. Correlational patterns are consistent with RLHF alignment effects, but alternative explanations remain possible.
\end{itemize}

\paragraph{Implications for Routing.}
This preference heterogeneity provides empirical justification for adaptive routing over static ``complexity'' heuristics. 
A static router based on ``difficulty'' might assume that strict, complex constraints require the strongest model. 
However, \texttt{banditGPT} learns the \emph{empirical} truth: on this subset of tasks, the cheaper model is preferred.
By identifying this structure, the router achieves cost reduction not just by offloading easy tasks, but by routing the subset of tasks where the cheaper model empirically excels.
