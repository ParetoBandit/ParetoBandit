\subsection{Model Preference Heterogeneity Analysis}
\label{sec:semantic_structure}

Before presenting our routing algorithm, we first establish that prompt structure correlates with differential model performance in the LMSYS held-out set.
Figure~\ref{fig:lmsys_holdout_structure} visualizes 750 held-out prompts projected onto the first principal component of a PCA model, revealing \textbf{model preference heterogeneity}: variation in which model is preferred across different prompt types.

\paragraph{Discrete Reward Structure.}
Reward gaps are derived from pairwise human preference evaluations (LMSYS Chatbot Arena), producing discrete outcomes: GPT-4-Turbo win ($\Delta > 0$), tie ($\Delta = 0$), or Mixtral win ($\Delta < 0$).
We therefore report outcome proportions and categorical statistics ($\chi^2$ test, Cram\'er's $V$) as the primary analysis, supplemented by ordinal tests (Mann-Whitney $U$).

\paragraph{Model Preference Heterogeneity.}
Using a silhouette-optimal threshold ($\text{PC1} = 0.222$, selected without reference to reward labels), we identify two clusters with significantly different outcome distributions:

\begin{itemize}[noitemsep,topsep=2pt]
    \item \textbf{Low PC1 Cluster (80.8\%, $n=606$):} Diverse conversational prompts where GPT-4-Turbo is preferred on aggregate (mean $\Delta = +0.121$).

    \item \textbf{High PC1 Cluster (19.2\%, $n=144$):} Prompts where Mixtral wins at a substantially higher rate and GPT-4-Turbo wins less often (mean $\Delta = -0.563$).
    Systematic TF-IDF analysis of distinctive terms reveals this cluster is enriched for instruction-following templates, binary classification tasks, structured output requirements, and explicit negative constraints (see Appendix for full keyword analysis).
    Note: this cluster proportion (19.2\%) is specific to the holdout sample; the 1M dataset shows $\sim$5.9\% in the corresponding spatial region.
\end{itemize}

\paragraph{Statistical Validation.}
The outcome distributions differ significantly between clusters ($\chi^2$ test: $p < 0.0001$, Cram\'er's $V$ reported in figure).
The ordinal Mann-Whitney $U$-test, appropriate for the discrete reward gap, also confirms the difference ($p < 0.0001$).

\paragraph{PCA Sensitivity.}
We validate that this finding is not an artifact of PCA provenance by repeating the analysis with two PCA models, both unsupervised (no reward labels used during training):

\begin{itemize}[noitemsep,topsep=2pt]
    \item \textbf{Generic PCA} (trained on 100K C4 web text samples, no routing connection): The effect is significant ($p < 0.0001$) with a small effect size (Cohen's $d = 0.33$). This is the unbiased baseline estimate.

    \item \textbf{Domain-adapted PCA} (trained on 80K routing prompts): The effect is significant ($p < 0.0001$) with a larger effect size ($d = 1.53$), consistent with task-relevant feature extraction concentrating routing-relevant variance into PC1.
\end{itemize}

\noindent The \textbf{primary, unbiased effect size} is $d = 0.33$ (small effect, generic PCA).
The domain-adapted PCA amplifies this $4.6\times$ to $d = 1.53$, partly because its training data (80K routing prompts) shares domain characteristics with the holdout set, concentrating routing-relevant variance into PC1.
The generic PCA result should be considered the conservative baseline for the effect's true magnitude.

\paragraph{Methodological Notes.}
\begin{itemize}[noitemsep,topsep=2pt]
    \item \textbf{Data:} Held-out test set only ($N=750$), created via stratified sampling (Appendix~\ref{app:stratification}). Dev set excluded.
    \item \textbf{Rewards:} Discrete pairwise outcomes from LMSYS Chatbot Arena human preference evaluations.
    \item \textbf{Threshold:} Silhouette-optimal ($\text{PC1} = 0.222$), selected without reward labels.
    \item \textbf{High-D structure:} Weak in 384D (silhouette $= 0.057$); PC1 captures moderate signal ($\rho^2 = 0.156$, explaining $\sim$16\% of reward gap variance).
    \item \textbf{Cluster diversity:} High PC1 is homogeneous (diversity $= 0.355$), consistent with a coherent semantic category.
    \item \textbf{Causal mechanism:} Not ablated. Correlational patterns suggest RLHF alignment effects, but alternative explanations remain possible.
    \item \textbf{Projection caveat:} The 384D silhouette score (0.057) indicates weak cluster structure in the full embedding space. The effect is primarily visible in the 2D projection (5.4\% of variance). While the generic PCA result ($d = 0.33$) argues against a pure projection artifact, this alternative explanation cannot be fully excluded.
    \item \textbf{Generalizability:} The cluster proportion (19.2\% High PC1) is specific to this holdout sample. The 1M dataset shows $\sim$5.9\% in the corresponding spatial region, suggesting the holdout may over-represent strict-constraint prompts relative to production traffic.
\end{itemize}

\paragraph{Implications for Routing.}
This preference heterogeneity provides empirical justification for adaptive routing over static ``complexity'' heuristics.
A static router based on ``difficulty'' might assume that strict, complex constraints require the strongest model.
However, \texttt{banditGPT} learns the \emph{empirical} truth: on this subset of tasks, the cheaper model is preferred.
By identifying this structure, the router achieves cost reduction not just by offloading easy tasks, but by routing the subset of tasks where the cheaper model empirically excels.
