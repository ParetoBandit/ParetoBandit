# Figure 1M: Semantic PCA of Full 1M Dataset

## Overview

This experiment extends the analysis from `01_figure` to the full 1M prompt dataset from RouteLLM. While the original experiment uses ~80k prompts from dev/holdout splits, this analysis processes the complete dataset to validate that the semantic structure and bimodal difficulty distribution holds at scale.

## Purpose

- **Validate at scale**: Confirm that the bimodal semantic structure observed in 80k prompts holds for the full 1M dataset
- **Robustness check**: Demonstrate that semantic clustering is not an artifact of data sampling
- **Comprehensive analysis**: Provide evidence that routing is learnable across the entire distribution of prompts

## Files

### Scripts
- `download_1M_dataset.py` - Downloads full 1M dataset from HuggingFace
- `plot_lmsys_1M_pca.py` - Performs PCA analysis and generates visualizations

### Data
- `data/battles_1M.jsonl.gz` - Processed 1M dataset (generated by download script)

### Results
- `results/figure1_lmsys_1M_pca.png` - Main visualization (300 DPI)
- `results/figure1_lmsys_1M_pca_hires.png` - High-resolution version (600 DPI)

## Running the Experiment

### Step 1: Download the 1M Dataset

```bash
cd /Users/annette/repostitories/banditGPT
python3 experiments_v1/01_figure_1M/download_1M_dataset.py
```

This will:
- Download the full RouteLLM dataset from HuggingFace (requires `HUGGINGFACE_API_KEY` in `.env`)
- Process battles into model evaluations format
- Save to `data/battles_1M.jsonl.gz`

Expected output:
- ~1M+ battles from the dataset
- Processed into individual model evaluations
- Filtered for prompts with both Mixtral and GPT-4-Turbo evaluations

### Step 2: Run PCA Analysis

```bash
cd /Users/annette/repostitories/banditGPT
python3 experiments_v1/01_figure_1M/plot_lmsys_1M_pca.py
```

This will:
- Load the 1M dataset
- Compute reward gaps (GPT-4-Turbo - Mixtral)
- Embed prompts using sentence-transformers
- Project to 2D using pre-trained PCA model
- Generate visualizations showing bimodal structure

## Expected Results

### Dataset Statistics
- **Total prompts**: ~1M (with both model evaluations)
- **Unique prompts**: Varies based on dataset
- **Models**: Mixtral-8x7B-Instruct vs GPT-4-Turbo

- **Bimodal distribution**: Clear separation between easy and hard tasks
- **PC1 clustering**: Low PC1 (<0.3) vs High PC1 (≥0.3) clusters
- **Reward gaps**: Distribution of GPT-4-Turbo - Mixtral scores

### Comparison with 01_figure
- **Original**: ~80k prompts from dev/holdout splits

2. **Semantic consistency**: Clustering patterns should match 80k analysis
