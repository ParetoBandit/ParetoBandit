# Security Policy

## Supported Versions

Currently, only the latest release of ParetoBandit is supported with security updates. We recommend users upgrade to the latest version to ensure they have the most recent security patches and bug fixes.

| Version | Supported          |
| ------- | ------------------ |
| v0.2.x  | :white_check_mark: |
| < v0.2  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in ParetoBandit, please do not open a public issue. We appreciate your efforts to responsibly disclose your findings.

Please report security issues by emailing:
**annette.taberner@gmail.com**

Please include the following information in your email:
* A description of the vulnerability and its potential impact
* The version(s) of ParetoBandit affected
* Step-by-step instructions to reproduce the issue
* Any potential mitigation or remediation steps you recommend

### Response Timeline

We take security seriously and will make every effort to respond to your report within 48 hours. If the vulnerability is verified, we will work with you to coordinate a timeline for a fix and public disclosure.
