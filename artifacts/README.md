# Artifacts Directory

This directory contains **static, versioned ML artifacts** used by BanditGPT for reproducibility and KDD validation.

## Contents

### `pca_32.joblib` (51 KB)
- **Purpose**: Pre-trained PCA model for dimensionality reduction
- **Input**: 384-dimensional sentence embeddings (MiniLM-L6-v2)
- **Output**: 32-dimensional compressed embeddings
- **Variance Captured**: ~60%
- **Training Data**: 1,000 synthetic prompts covering 5 archetypes (math, coding, reasoning, creative, chat)
- **Usage**: Loaded by `BanditRouter` during initialization for efficient feature extraction

### Future Artifacts
- `priors_warmup.joblib`: Pre-computed warmup priors from synthetic IRT simulation (when generated)
- `complexity_vector.npz`: Reference complexity calibration vector

## Directory Structure Philosophy

```
banditGPT/
├── artifacts/           # ✅ Static ML artifacts (versioned, reproducible)
├── data/               # ❌ Runtime data (gitignored, grows over time)
│   ├── router_context.db        # 612 MB and growing
│   └── priors_warmup.joblib     # Generated by scripts
└── src/bandit_gpt/data/
    └── offline_dataset/ # ✅ Static evaluation datasets (compressed)
```

## KDD Rationale

**Reproducibility**: Academic reviewers can use exact same artifacts to validate results

**Separation of Concerns**:
- `artifacts/` = science (static, versioned)
- `data/` = engineering (dynamic, local)

## Regenerating Artifacts

If artifacts need to be regenerated (e.g., after encoder upgrade):

```bash
# PCA model
python src/bandit_gpt/data/scripts/train_pca.py

# Warmup priors (future)
python scripts/generate_warmup.py
```

The router has **self-healing** capabilities: if `pca_32.joblib` is missing or has dimension mismatches, it will auto-train a new PCA model via JIT calibration.
