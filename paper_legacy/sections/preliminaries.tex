\section{Preliminaries}
\label{sec:preliminaries}

This section formalizes the LLM routing problem as a cost-aware contextual bandit, introduces the feature representation, and reviews the two algorithmic building blocks---LinUCB and Corralling---that underpin the banditGPT architecture.

\subsection{Problem Formulation}
\label{sec:formulation}

Let $x_t \in \mathbb{R}^d$ denote the context vector (embedding) for a user prompt at time $t$. We maintain a dynamic registry of models (arms) $\mathcal{M}_t$. For each request, the policy $\pi$ selects an arm $a_t \in \mathcal{M}_t$, observing a scalar reward $r_t \in [0, 1]$ (quality) and incurring a deterministic cost $c_t \in \mathbb{R}^+$ (inference price).

Unlike standard regret minimization, our objective is to maximize quality subject to a budget constraint, formulated as a Lagrangian relaxation with a user-defined penalty $\lambda$:
\begin{equation}
\text{Maximize } \sum_{t=1}^T \left( \mathbb{E}[r_t(a_t) | x_t] - \lambda \cdot c_t(a_t) \right)
\end{equation}
where $\lambda$ controls the trade-off between performance and economy. A high $\lambda$ forces the router to identify ``easy'' prompts where cheaper models suffice, while a low $\lambda$ prioritizes quality regardless of cost.

\subsection{Background: LinUCB and Expert Corralling}
\label{sec:background}

\paragraph{LinUCB.}
LinUCB~\cite{li2010contextual} models the expected reward of each arm $a$ as a linear function of the context: $\mathbb{E}[r | x] = x^\top \theta^*_a$. It maintains a regularized least-squares estimate $\hat{\thetavec}_a$ and an associated confidence set, selecting the arm that maximizes an upper confidence bound on the composite utility. LinUCB provides a natural framework for contextual routing because per-prompt embeddings allow the policy to vary model selection with input content.

\paragraph{Expert Corralling.}
Corralling~\cite{agarwal2017corralling} is a meta-learning strategy that maintains a portfolio of expert policies, dynamically allocating probability mass among them via exponential weight updates. By ensuring non-zero probability on each expert, it provides asymptotic recovery guarantees when the optimal expert changes over time. In our setting, Corralling enables safe hedging against prior misspecification by maintaining both a warm-started and a tabula rasa expert.

\subsection{Unified Feature Space and Empirical Validation}
\label{sec:motivation}

A contextual bandit is only useful if prompt features carry actionable routing signal.
We embed prompts using \texttt{BAAI/bge-m3}~\cite{chen2024bge} (1024D) and reduce to 15 dimensions using unsupervised PCA trained on ${\sim}46{,}000$ LMSYS Chatbot Arena prompts disjoint from the evaluation splits.

To validate that these features predict model preference, we evaluate on $N{=}750$ held-out prompts scored by all $K{=}10$ models in our portfolio (three cost tiers, four providers).
Rewards are computed as $\text{mean}(\text{vote} \times \text{confidence})$ across a 3--4 judge panel (\S\ref{app:cot_panel}), yielding a continuous signal in $[0,1]$ that preserves evaluative nuance lost by binarised majority vote.

For each model~$m$, we fit $r_{i,m} = \alpha_m + \gamma_m \widetilde{\text{PC1}}_i + \varepsilon_{i,m}$, where $\widetilde{\text{PC1}}$ is the standardised first principal component.
A likelihood-ratio test comparing per-model slopes against a shared-slope null (6~PCA components, $\text{df}{=}54$) decisively rejects the null: $\chi^2 = 771.3$, $p < 10^{-15}$ (Figure~\ref{fig:contextual_heterogeneity}A).
Context affects models differently---precisely the condition under which contextual routing outperforms static assignment.

All ten bootstrap 95\% CIs exclude zero (Figure~\ref{fig:contextual_heterogeneity}B), but magnitudes span nearly an order of magnitude: from $|\gamma| = 0.032$ (GPT-4.1, least context-sensitive) to $|\gamma| = 0.254$ (GPT-4-Turbo, most context-sensitive).
The regression lines cross, confirming that no single model dominates the full feature space.
Furthermore, the per-prompt oracle gain (best-model reward minus mean-model reward) correlates with PC1 at Spearman $\rho = {+}0.424$ ($p < 10^{-33}$), exceeding all 100 random orthonormal projections ($3.4\times$ the null median).

These results establish three architectural requirements for \textit{banditGPT}:
\begin{enumerate}[noitemsep,topsep=2pt,leftmargin=*]
    \item \textbf{Exploit Contextual Signal:} Embeddings carry actionable model-preference information whose strength varies across models, enabling a contextual bandit to route each prompt to its best model.
    \item \textbf{Avoid Static Policies:} No single model dominates: the best model varies with prompt features. A static policy is constrained to the best single model (GPT-4.1, mean reward $0.910$), leaving the 79.5\% of prompts where contextual selection improves unaddressed.
    \item \textbf{Safe Online Learning:} Because the preference landscape depends on the deployment distribution, routers must adapt online while hedging against misleading offline priors (verified in Section~\ref{sec:distribution_shift}).
\end{enumerate}
