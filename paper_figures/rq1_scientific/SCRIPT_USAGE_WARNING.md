## The Problem: Data Leakage in Old Script

### `/experiments/run_rq1.py` (❌ INVALID FOR PAPER)

```python
class ExperimentConfig:
    priors_path = "expert_priors.npz"        # Trained on archetype_grid
    prompts_path = "archetype_grid_prompts.jsonl"  # SAME DATA
```

**Issue:** The script evaluates on the **same prompts** used to train the priors.

**Result:** Optimistic performance (e.g., "64% regret reduction")

**What it measures:** In-sample calibration efficiency (memorization)

**Why it's wrong:** This is not generalization! It's testing whether the agent can memorize its training set.

**Analogy:** It's like training a student on past exam questions, then giving them the exact same questions on the test. High scores don't prove learning.

---

```python

for fold in range(5):
    train_indices = [...]  # 398 prompts

    # Train priors on train_indices
```

**What it does:** Proper train/test split with no overlap

**Result:** Honest performance (+32% regret increase)

**What it measures:** Out-of-sample generalization

**Why it's right:** This tests whether priors trained on one set of prompts help on a completely different set—which is what happens in real deployment.
