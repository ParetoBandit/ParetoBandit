\begin{abstract}
Production LLM serving increasingly relies on multi-model portfolios spanning a $530\times$ cost range, yet no existing routing system simultaneously enforces dollar-denominated budgets, adapts to non-stationary model quality and pricing, and onboards new models at runtime without downtime.

We present ParetoBandit, an open-source adaptive routing system built on cost-aware contextual bandits. Three design choices target these deployment gaps. First, an online primal-dual budget pacer accepts a per-request cost target and enforces it over an open-ended stream with no known horizon, replacing offline penalty tuning with closed-loop cost control. Second, geometric forgetting on the bandit's sufficient statistics enables rapid adaptation to price drops and catastrophic model failures while preserving offline warmup priors. Third, a hot-swap model registry lets operators add or remove models at runtime via a single API call; the bandit's exploration bonus discovers the newcomer's quality--cost niche from live traffic alone.

We evaluate on 1,785 prompts routed across three models. ParetoBandit maintains budget compliance within $0.98$--$1.00\times$ of the target at binding budgets, and correctly under-spends when the quality-optimal policy is already cheaper than the target. Under a mid-cycle price drop the system delivers a $+0.073$ quality lift. Under catastrophic model failure it redistributes traffic while staying on budget. A cold-started model reaches sustained adoption within ${\sim}200$ steps. End-to-end routing latency is $8.3$\,ms on CPU, with the routing decision itself taking $22\,\mu$s, under $1\%$ of typical LLM inference time.
\end{abstract}
