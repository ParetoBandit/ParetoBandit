# Experiment Artifacts

This directory contains pre-computed artifacts used by the experiment suite
(not shipped in the `paretobandit` pip package).

## `splits_three_way.json`

Stratified three-way split of prompts into prior-training, online-learning,
and holdout pools.  Prompts originate from the
[LMSYS Chatbot Arena](https://huggingface.co/datasets/lmsys/chatbot_arena_conversations)
dataset (CC-BY-4.0).

Some prompts contain embedded code snippets, file paths, or configuration
fragments that are part of the original user queries — these are **not**
project secrets or hardcoded paths.

## `*.joblib`

Warmup prior matrices for various PCA component counts and model-set
configurations.  Generated by `scripts/generate_multimodel_warmup_priors.py`.
