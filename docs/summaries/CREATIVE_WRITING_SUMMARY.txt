================================================================================
EVALUATION PROCESS
================================================================================

1. Generation (5-10 min)
   - 32 prompts across diverse genres
   - 3 iterations per prompt
   - 96 total pieces per model
   - Temperature 0.7, Min_p 0.1

2. Rubric Scoring (5-10 min)
   - Each piece judged independently
   - Claude Sonnet 4 as judge
   - 0-100 score per piece

3. Elo Calculation (5-10 min)
   - Initial Elo from rubric scores
   - Pairwise matchups with neighbors
   - Glicko-2 system with win margins
   - Normalized to leaderboard

Total Time: 15-30 minutes per model
Total Cost: ~$10 per model ($3-5 generation, $5-7 judging)
