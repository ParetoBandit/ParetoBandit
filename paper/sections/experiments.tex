\subsection{Experimental Setup}
\label{sec:experiments}

We evaluate banditGPT on the data and splits described in Section~\ref{sec:data}, using commercial per-request costs for each model. Additional evaluations (multi-model scaling, alternative bandit baselines, regret curves, and robustness stress tests) are reported in the appendix (supplementary material).

\subsubsection{Model Topology \& Baselines}

We mirror standard $K{=}2$ evaluation topologies~\cite{ong2024routellm}:

\begin{itemize}[nosep,leftmargin=*]
    \item \textbf{Cheaper Open-Weights Model} (Cost: $\approx$ \$0.30 per 1M tokens).
    \item \textbf{Expensive Frontier Model} (Cost: $\approx$ \$10.00 to \$30.00 per 1M tokens).
\end{itemize}

We compare against static single-model baselines, random routing, RouteLLM-MF~\cite{ong2024routellm}, and an oracle upper bound that selects the better model per prompt.

\subsubsection{Evaluation Metrics}

We evaluate performance using three key metrics standard in cost-aware routing literature:

\begin{itemize}[nosep,leftmargin=*]
    \item \textbf{Average Reward ($\bar{r}$)}: The mean quality score of the selected responses.
    
    \item \textbf{Normalized Cost ($\bar{c}$)}: The average inference cost, normalized such that the expensive frontier model $\approx 1.0$.
    
    \item \textbf{Gap Closure (\%)}: The percentage of the performance gap between the cheaper model and the Oracle that the router recovers, defined as:
    \begin{equation}
    \text{Gap Closure} = \frac{R_{\text{router}} - R_{\text{cheaper}}}{R_{\text{oracle}} - R_{\text{cheaper}}} \times 100\%
    \end{equation}
\end{itemize}
