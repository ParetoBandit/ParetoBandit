\begin{abstract}
Large language model (LLM) inference is economically critical yet technically challenging: expensive models aren't always better, and training data distributions shift over time. We present \textbf{banditGPT}, an open-source, cost-aware contextual bandit framework for LLM routing that combines semantic structure discovery with adaptive online learning.

Our key insight is that LLM routing is a \emph{discovery} problem, not an interpolation problem: the expensive model is not merely unnecessary on some tasks---it is \emph{actively worse} on an identifiable subset. On held-out LMSYS prompts ($N=750$), model preference varies by prompt and the router's features predict this variation (Spearman $\rho = -0.370$, $p < 0.0001$, exceeding all 100 random projections). When the state-of-the-art static router (RouteLLM) cannot distinguish these prompts, it pays $43\times$ more for $1.3\%$ \emph{lower} quality.

banditGPT addresses this through two verified mechanisms: (1) \textbf{cost-aware contextual bandits} initialized from offline warmup priors (80k RouteLLM battles) that surpass RouteLLM's peak quality after only 400 label-free in-distribution prompts, and (2) \textbf{Corralling meta-learning} that hedges against misleading training priors ($1$--$4\%$ overhead under moderate shift, with catastrophic failure protection). The framework natively supports multi-model portfolios ($K \geq 3$) with continuous cost-quality Pareto optimization---unlike threshold-based routers restricted to $K{=}2$. Production validation demonstrates $70.8\%$ gap closure to oracle (vs $46.2\%$ for RouteLLM).

We also investigate semantic transfer for cold-starting new models and report a \emph{null result}: in controlled ablations with proper statistical power, transferred priors provide no significant advantage over tabula rasa initialization, establishing an honest boundary on current bandit routing capabilities.
\end{abstract}
