\begin{abstract}
Deploying Large Language Models (LLMs) requires balancing generation quality and inference cost. While static LLM routers optimize this tradeoff initially, their performance often degrades under shifting user distributions and evolving model landscapes. Empirically, prompt embeddings moderately predict per-prompt model preference (Spearman $\rho{=}{-}0.370$, $p{<}0.0001$), rendering ``best-on-average'' static routing suboptimal. Contextual bandits offer an adaptive alternative but often face cold-start penalties, struggle with misleading offline priors, lack explicit hedging against misspecified priors, and lack strict budget enforcement.

To address these gaps, we introduce \textit{banditGPT}, an open-source contextual bandit library for dynamic LLM routing. It features three key contributions: (1) offline-to-online prior transfer via contextual LinUCB for production-quality routing from the first request; (2) a Corralling meta-learner that safely hedges against distribution shifts by balancing offline priors with online \textit{tabula rasa} exploration; and (3) hard per-request budget and latency constraints.

Evaluations across six commercial providers with a 520$\times$ cost range demonstrate \textit{banditGPT}'s effectiveness. It achieves up to a 91\% cost reduction with only 6\% quality degradation compared to exclusive frontier-model routing. Ablations confirm online learning yields a $+7.0$ percentage-point gain over frozen priors, while the Corralling meta-learner adds a further $+1.3$\,pp; notably, the source of offline priors has no significant effect ($p{>}0.18$). Across portfolio sizes $K{\in}\{2, 3\}$, \textit{banditGPT} closes 61--75\% of the optimality gap to a theoretical oracle within hundreds of interactions. Code and warmup priors are open-sourced to facilitate research in adaptive LLM routing.
\end{abstract}
