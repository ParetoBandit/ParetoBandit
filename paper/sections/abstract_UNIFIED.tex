\begin{abstract}
Large language model (LLM) inference is economically critical yet technically challenging: expensive models are not always better, and training data distributions shift over time. We present \textbf{banditGPT}, an open-source, cost-aware contextual bandit framework for LLM routing that combines semantic structure discovery with adaptive online learning.

Our key insight is that LLM routing is a \emph{discovery} problem, not an interpolation problem: the expensive model is not merely unnecessary on some tasks---it is \emph{actively worse} on an identifiable subset. On held-out LMSYS prompts ($N{=}750$), model preference varies systematically by prompt, and the router's PCA features predict this variation (Spearman $\rho = -0.370$, $p < 0.0001$, exceeding all 100 random projections). When the state-of-the-art static router (RouteLLM) cannot distinguish these prompts, it pays $43\times$ more for $1.3\%$ \emph{lower} quality.

banditGPT addresses this through two mechanisms: (1)~\textbf{cost-aware contextual bandits} initialized from offline warmup priors (80k RouteLLM battles) that surpass RouteLLM's peak quality after approximately 200 label-free in-distribution prompts, achieving $70.0\%$ gap closure to oracle (vs.\ $46.2\%$ for RouteLLM) at moderate-to-high budgets; and (2)~\textbf{Corralling meta-learning} that hedges against misleading training priors, providing bounded worst-case regret ($1$--$4\%$ overhead under moderate shift, with catastrophic failure detection at $K{\geq}5$). At low budgets, RouteLLM's pre-trained prompt-level discrimination remains competitive, reflecting the complementary strengths of supervision scale and online adaptation. The framework natively supports multi-model portfolios ($K \geq 3$) with continuous cost-quality Pareto optimization, combining online adaptation, meta-learning safety, and multi-model routing in a single open-source system. We additionally report a null result on semantic transfer for cold-starting new models, establishing a boundary on current bandit routing capabilities.
\end{abstract}
