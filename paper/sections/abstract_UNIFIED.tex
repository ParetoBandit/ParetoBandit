\begin{abstract}
Large language model (LLM) inference is costly, and the best model for a given prompt can vary across tasks and shift over time. We present \textbf{banditGPT}, an open-source contextual bandit framework for cost-aware LLM routing that combines three mechanisms: (1)~\textbf{cost-aware LinUCB} initialized from offline priors and refined through label-free bandit feedback, (2)~\textbf{Corralling meta-learning} that hedges against imperfect or misleading priors by dynamically weighting complementary exploration strategies, and (3)~\textbf{multi-model portfolio support} with hard budget constraints, family-based parameter sharing, and dynamic model onboarding.

On $N{=}750$ held-out LMSYS Arena prompts, banditGPT closes \textbf{70.0\%} of the gap to an oracle router after 300--400 in-distribution online interactions, using only automated reward signals during the adaptation phase. Warmup priors from offline preference data provide competitive initial routing before any online feedback. With online adaptation, banditGPT traces a continuous cost--quality \textbf{Pareto frontier}, achieving up to 89\% cost reduction with less than 6\% quality loss in multi-model evaluations ($K{=}10$). Corralling reduces cumulative regret by 7--13\% over warmup-only baselines across all tested prior corruption levels, and the system exhibits strong \textbf{hyperparameter robustness}: reward varies less than 0.5\% across a $50\times$ range of meta-learning rates.

We evaluate banditGPT on portfolios of $K{=}2$, $5$, and $10$ models spanning six providers and a $600\times$ cost range. In controlled experiments, new models integrate via a single API call, reaching calibration within ${\sim}600$ routing decisions. We release the full codebase, warmup priors, and experimental logs to support reproducibility.
\end{abstract}
