\subsection{Statistical Validation of Semantic Structure}
\label{app:validation_methodology}

We perform comprehensive validation to ensure our model preference heterogeneity findings (Figure~\ref{fig:lmsys_holdout_structure}) are statistically robust and not artifacts of methodological choices. The primary analysis uses Spearman rank correlation (Section~\ref{sec:motivation}); this appendix provides supplementary clustering-based analyses for additional context. All analyses use the held-out test set exclusively ($N=750$).

\subsubsection{Statistical Significance Testing}

We validate the cluster distinction using multiple tests robust to distributional assumptions:

\paragraph{Primary Tests.}
\begin{itemize}[leftmargin=*,noitemsep,topsep=0pt]
    \item \textbf{Mann-Whitney $U$-test (non-parametric):} $p < 0.0001$
    \item \textbf{Effect size (Cohen's $d$):} $1.53$ (large effect, $d > 0.8$)
    \item \textbf{Confidence intervals (95\%):} Low PC1: $[+0.088, +0.153]$, High PC1: $[-0.661, -0.464]$ (non-overlapping)
\end{itemize}

\paragraph{Distribution Diagnostics.}
Shapiro-Wilk normality tests indicate both distributions are non-normal ($p < 0.001$), justifying the use of non-parametric tests.

\subsubsection{Threshold Validation}

The $\text{PC1} = 0.222$ threshold was selected using a purely unsupervised method: silhouette-optimal threshold search, maximizing geometric cluster quality without reference to reward labels (silhouette score $= 0.499$). This avoids the methodological concern of threshold selection bias from reward-based grid search.

\paragraph{Unsupervised Clustering.}
Independent clustering methods identify consistent structure:
\begin{itemize}[leftmargin=*,noitemsep,topsep=0pt]
    \item Silhouette-optimal threshold: $\text{PC1} = 0.222$ (silhouette $= 0.499$)
    \item $k$-means clustering ($k=2$): boundary $\approx 0.138$
    \item Both methods yield $p < 0.0001$ with Cohen's $d > 1.0$
\end{itemize}

\paragraph{Sensitivity Analysis.}
The effect is robust across a range of thresholds. Both $k$-means ($\text{PC1} = 0.138$, $d = 1.15$) and silhouette-optimal ($\text{PC1} = 0.222$, $d = 1.53$) thresholds produce highly significant results, demonstrating that the finding is not dependent on a specific threshold choice.

\subsubsection{High-Dimensional Structure Validation}

To assess whether the bimodal structure exists beyond the 2D projection, we examined cluster quality across multiple dimensionalities:

\begin{table}[h]

\label{tab:multidim_validation}
\begin{tabular}{lccc}
\toprule
\textbf{Space} & \textbf{Dimensions} & \textbf{Silhouette} & \textbf{Separation Ratio} \\
\midrule

The 384D silhouette score of 0.057 indicates \textbf{weak cluster structure} in the full embedding space---clusters overlap substantially. The separation ratio of 0.81 ($< 1.0$) confirms that within-cluster distances exceed between-cluster distances in high dimensions. This is an important caveat: the structure detected by PC1 represents a task-relevant signal extracted from a noisy high-dimensional space, not a dominant clustering pattern. The PC1 projection isolates this signal (Spearman $\rho = -0.370$, $\rho^2 = 0.137$, explaining ${\sim}14\%$ of reward gap variance---a moderate correlation), but the remaining ${\sim}86\%$ of variance is driven by other factors (topic, length, complexity) orthogonal to model preference.

\subsubsection{Data Quality Analysis}

The held-out dataset ($N=750$) contains zero exact duplicates. Intra-cluster diversity analysis shows:
\begin{itemize}[leftmargin=*,noitemsep,topsep=0pt]
    \item High PC1 diversity score: 0.355 (average pairwise cosine similarity: 0.645)
    \item Low PC1 diversity score: 0.953 (average pairwise cosine similarity: 0.047)
\end{itemize}

The High PC1 cluster is relatively homogeneous (diversity $= 0.355$), consistent with a coherent semantic category of strict-format prompts rather than a broad, diverse phenomenon. The Low PC1 cluster is highly diverse, representing the full range of conversational prompt types. This asymmetry should be considered when interpreting the generalizability of the preference inversion finding.

\subsubsection{Summary of Validation}

\begin{enumerate}[leftmargin=*,noitemsep,topsep=0pt]
    \item \textbf{Primary metric:} Spearman $\rho = -0.370$, $p < 0.0001$ (features predict model preference)
    \item \textbf{Null baseline:} Router PCA $|\rho|$ exceeds all 100 random projections (2.6$\times$ vs.\ median)
    \item \textbf{Supplementary clustering:} Threshold-based analyses (silhouette-optimal, $k$-means) confirm directional finding
    \item \textbf{High-D caveat:} Weak structure in 384D (silhouette $= 0.057$); PC1 isolates a moderate signal ($\rho^2 \approx 0.14$)
    \item \textbf{Data quality:} Zero duplicates; High PC1 region is a homogeneous cluster (diversity $= 0.355$)
    \item \textbf{Held-out only:} All analyses on $N=750$ test set; dev set excluded
\end{enumerate}

\paragraph{Key Findings.}
\begin{enumerate}[nosep]
    \item \textbf{Learning Rate:} Higher rates ($\eta \geq 1.0$) enable faster expert adaptation. The optimal $\eta=5.0$ achieves aggressive weight updates while maintaining stability through the exploration floor ($\gamma=0.10$).
    
    \item \textbf{Exploration Floor:} The mixing parameter ($\gamma > 0$) prevents expert starvation and stabilizes learning. Configurations with $\gamma=0$ exhibit $14\times$ higher variance (e.g., $\eta=2.0$, $\gamma=0.0$: std=54.46 vs std=3.40 for optimal), while $\gamma=0.10$ yields consistent performance.
    
    \item \textbf{Reproducibility:} The optimal configuration demonstrates low variance across seeds (std=3.40), confirming results are not due to fortunate initialization.
    
    \item \textbf{Robustness:} Performance remains competitive across $\eta \in [0.5, 5.0]$ when $\gamma \geq 0.05$, indicating reasonable tolerance to hyperparameter misspecification.
\end{enumerate}

\paragraph{Convergence Validation.}
Log-log regression (excluding 50-sample burn-in) yields growth exponent $\beta=0.669 \pm 0.002$ with $R^2=0.9903$, confirming sublinear regret growth $O(T^{0.669})$ and satisfying the PAC-learnability criterion ($\beta < 1$).

\paragraph{Cold-Start Model Integration.}
Since warmup priors cover only Mixtral and GPT-4-Turbo, GPT-4o is initialized from GPT-4-Turbo's learned preferences with conservative scaling ($\gamma=0.05$). At $\lambda=0$ (quality only), the bandit rapidly discovers GPT-4o as the dominant choice (64.6\% usage, 5-seed average), correctly identifying the warmup expert's GPT-4-Turbo bias as suboptimal. At $\lambda=0.1$, GPT-4o usage rises to 74.3\% as cost awareness further penalizes GPT-4-Turbo. Note that this rapid convergence is driven by the online learning mechanism rather than the transferred prior itself (see Section~\ref{sec:transfer_null}).

\paragraph{Validation Protocol.}
Evaluate warmup predictions on $N=100$--$200$ deployment samples.
Start with Corralling (library default) and monitor the first 50--100
prompts.  If warmup expert accuracy falls below random chance, switch to
tabula rasa to cap downside risk.

\paragraph{Key Findings.}
(1)~Corralling dominates both warmup-only and tabula rasa for
good-to-moderate priors ($\alpha \leq 0.5$), achieving 29--39\% lower
regret;
(2)~Tabula Rasa is optimal when priors are known-bad or truly uncertain;
(3)~Warmup-only is \emph{never} optimal at any corruption level and should
be migrated to Corralling in all cases;
(4)~The 53\% breakeven threshold provides a principled decision rule.
All configurations use constant $\alpha=2.0$.
