\subsection{Reward Signal Specification}
\label{app:reward_signal}

This subsection provides the full reward signal details referenced in Section~\ref{sec:reward_signal}.

\subsubsection{$K{=}2$ Rewards (Pairwise, Ternary)}

All 1,871 LMSYS evaluation prompts are judged by GPT-4o (\texttt{openai/gpt-4o}, accessed via OpenRouter) at temperature~0 (deterministic).
The judge receives both model responses in a pairwise comparison using RouteLLM's MT-Bench-style template, which evaluates helpfulness, relevance, accuracy, depth, creativity, and level of detail.
Output is \texttt{[[A]]}, \texttt{[[B]]}, or \texttt{[[C]]} (tie), mapped to $r \in \{0, 0.5, 1\}$.

The 80K RouteLLM warmup battles ship with pre-existing pairwise labels from the \texttt{routellm/gpt4\_judge\_battles} HuggingFace dataset.
The winner labels in the dataset encode the \emph{losing} model (an inversion noted and corrected in \texttt{scripts/download\_and\_process\_routellm.py}).

\subsubsection{$K{>}2$ Rewards (Cross-Provider LLM Panel)}
\label{app:cot_panel}

The 10 models used in the $K{=}5$ and $K{=}10$ experiments are judged by a panel of LLMs drawn from four providers:

\begin{itemize}[leftmargin=*,noitemsep]
    \item \textbf{GPT-4o} (\texttt{openai/gpt-4o})
    \item \textbf{Claude-3.5-Sonnet} (\texttt{anthropic/claude-3.5-sonnet})
    \item \textbf{Llama-3.1-405B} (\texttt{meta-llama/llama-3.1-405b-instruct})
    \item \textbf{Gemini-2.5-Pro} (\texttt{google/gemini-2.5-pro-preview-06-05})
\end{itemize}

\paragraph{Cross-provider constraint.}
To prevent self-evaluation bias, a judge never evaluates models from its own provider family.
For example, when judging \texttt{openai/gpt-4.1}, the OpenAI judge (GPT-4o) is excluded and the model is scored by the remaining 3 judges (Claude-3.5-Sonnet, Llama-3.1-405B, Gemini-2.5-Pro).
Provider families are determined by prefix matching: all \texttt{openai/*} models map to ``openai'', \texttt{anthropic/*} to ``anthropic'', etc.

\paragraph{Chain-of-thought prompt template.}
Each judge receives the following system prompt at temperature~0:

\begin{quote}
\small\ttfamily
You are an impartial judge evaluating the quality of an LLM response.\\
Please follow this Chain-of-Thought process:\\
1. Provide a concise reasoning explanation.\\
2. Cast a VOTE: 1 (Pass/Good) or 0 (Fail/Bad).\\
3. Assign a CONFIDENCE score (0-100\%) reflecting your certainty.\\[0.5em]
Format your response exactly as follows:\\[0.5em]
\#\# Reasoning\\
<reasoning text>\\[0.3em]
\#\# Vote\\
<0 or 1>\\[0.3em]
\#\# Confidence\\
<0-100>
\end{quote}

The user message contains the original prompt and the model's response in the format: \texttt{PROMPT: <prompt> \textbackslash n\textbackslash n RESPONSE: <response>}.

\paragraph{Reward aggregation.}
Each judge casts a binary vote ($v \in \{0, 1\}$) with an explicit confidence score ($c \in [0, 1]$).
The per-prompt reward is the mean vote across the panel:
\begin{equation}
r(q, m) = \frac{1}{|J_m|} \sum_{j \in J_m} v_j
\end{equation}
where $J_m$ is the set of judges eligible to evaluate model~$m$ (i.e., judges not from $m$'s provider family).
This yields a continuous signal in $[0, 1]$ that preserves evaluative granularity---for example, a 2-of-3 pass maps to $0.67$ rather than being binarised to $1.0$.

\subsubsection{Known Limitations}

\begin{enumerate}[leftmargin=*,noitemsep]
    \item \textbf{LLM-as-judge bias:} Judge biases (e.g., verbosity preference, position bias) propagate into the reward signal.
          \emph{Mitigation:} The banditGPT framework is reward-agnostic; the judge can be replaced with human feedback or task-specific metrics.
    \item \textbf{No human validation:} We do not validate judge labels against human preferences on this specific dataset.
          \emph{Mitigation:} The router's learned predictions align closely with observed rewards (bias $< 0.05$), as verified by calibration analysis in the repository artifacts.
    \item \textbf{Deterministic judging:} Temperature~0 eliminates within-prompt reward noise but may mask borderline cases.
          \emph{Mitigation:} The 20-seed protocol captures across-trial variance.
    \item \textbf{Cross-regime reward scale:} $K{=}2$ uses ternary rewards $\{0, 0.5, 1\}$ while $K{>}2$ uses continuous $[0, 1]$. Both are valid inputs to LinUCB but are not directly comparable in magnitude.
\end{enumerate}

The full evaluation script is available at \texttt{scripts/rejudge\_cot.py} in the open-sourced repository.

\subsection{Statistical Validation of Semantic Structure}
\label{app:validation_methodology}

We perform comprehensive validation to ensure our model preference heterogeneity findings (Figure~\ref{fig:lmsys_holdout_structure}) are statistically robust and not artifacts of methodological choices. The primary analysis uses Spearman rank correlation (Section~\ref{sec:motivation}); this appendix provides supplementary clustering-based analyses for additional context. All analyses use the held-out test set exclusively ($N=750$).

\subsubsection{Statistical Significance Testing}

We validate the cluster distinction using multiple tests robust to distributional assumptions:

\paragraph{Primary Tests.}
\begin{itemize}[leftmargin=*,noitemsep,topsep=0pt]
    \item \textbf{Mann-Whitney $U$-test (non-parametric):} $p < 0.0001$
    \item \textbf{Effect size (Cohen's $d$):} $1.53$ (large effect, $d > 0.8$)
    \item \textbf{Confidence intervals (95\%):} Low PC1: $[+0.088, +0.153]$, High PC1: $[-0.661, -0.464]$ (non-overlapping)
\end{itemize}

\paragraph{Distribution Diagnostics.}
Shapiro-Wilk normality tests indicate both distributions are non-normal ($p < 0.001$), justifying the use of non-parametric tests.

\subsubsection{Threshold Validation}

The $\text{PC1} = 0.222$ threshold was selected using a purely unsupervised method: silhouette-optimal threshold search, maximizing geometric cluster quality without reference to reward labels (silhouette score $= 0.499$). This avoids the methodological concern of threshold selection bias from reward-based grid search.

\paragraph{Unsupervised Clustering.}
Independent clustering methods identify consistent structure:
\begin{itemize}[leftmargin=*,noitemsep,topsep=0pt]
    \item Silhouette-optimal threshold: $\text{PC1} = 0.222$ (silhouette $= 0.499$)
    \item $k$-means clustering ($k=2$): boundary $\approx 0.138$
    \item Both methods yield $p < 0.0001$ with Cohen's $d > 1.0$
\end{itemize}

\paragraph{Sensitivity Analysis.}
The effect is robust across a range of thresholds. Both $k$-means ($\text{PC1} = 0.138$, $d = 1.15$) and silhouette-optimal ($\text{PC1} = 0.222$, $d = 1.53$) thresholds produce highly significant results, demonstrating that the finding is not dependent on a specific threshold choice.

The 384D silhouette score of 0.057 indicates \textbf{weak cluster structure} in the full embedding space---clusters overlap substantially. The separation ratio of 0.81 ($< 1.0$) confirms that within-cluster distances exceed between-cluster distances in high dimensions. This is an important caveat: the structure detected by PC1 represents a task-relevant signal extracted from a noisy high-dimensional space, not a dominant clustering pattern. The PC1 projection isolates this signal (Spearman $\rho = -0.370$, $\rho^2 = 0.137$, explaining ${\sim}14\%$ of reward gap variance---a moderate correlation), but the remaining ${\sim}86\%$ of variance is driven by other factors (topic, length, complexity) orthogonal to model preference.

\subsubsection{Data Quality Analysis}

The held-out dataset ($N=750$) contains zero exact duplicates. Intra-cluster diversity analysis shows:
\begin{itemize}[leftmargin=*,noitemsep,topsep=0pt]
    \item High PC1 diversity score: 0.355 (average pairwise cosine similarity: 0.645)
    \item Low PC1 diversity score: 0.953 (average pairwise cosine similarity: 0.047)
\end{itemize}

The High PC1 cluster is relatively homogeneous (diversity $= 0.355$), consistent with a coherent semantic category of strict-format prompts rather than a broad, diverse phenomenon. The Low PC1 cluster is highly diverse, representing the full range of conversational prompt types. This asymmetry should be considered when interpreting the generalizability of the preference inversion finding.

\subsubsection{Summary of Validation}

\begin{enumerate}[leftmargin=*,noitemsep,topsep=0pt]
    \item \textbf{Primary metric:} Spearman $\rho = -0.370$, $p < 0.0001$ (features predict model preference)
    \item \textbf{Null baseline:} Router PCA $|\rho|$ exceeds all 100 random projections (2.6$\times$ vs.\ median)
    \item \textbf{Supplementary clustering:} Threshold-based analyses (silhouette-optimal, $k$-means) confirm directional finding
    \item \textbf{High-D caveat:} Weak structure in 384D (silhouette $= 0.057$); PC1 isolates a moderate signal ($\rho^2 \approx 0.14$)
    \item \textbf{Data quality:} Zero duplicates; High PC1 region is a homogeneous cluster (diversity $= 0.355$)
    \item \textbf{Held-out only:} All analyses on $N=750$ test set; dev set excluded
\end{enumerate}

\paragraph{Key Findings.}
\begin{enumerate}[nosep]
    \item \textbf{Learning Rate:} Higher rates ($\eta \geq 1.0$) enable faster expert adaptation. The optimal $\eta=5.0$ achieves aggressive weight updates while maintaining stability through the exploration floor ($\gamma=0.10$).
    
    \item \textbf{Exploration Floor:} The mixing parameter ($\gamma > 0$) prevents expert starvation and stabilizes learning. Configurations with $\gamma=0$ exhibit $14\times$ higher variance (e.g., $\eta=2.0$, $\gamma=0.0$: std=54.46 vs std=3.40 for optimal), while $\gamma=0.10$ yields consistent performance.
    
    \item \textbf{Reproducibility:} The optimal configuration demonstrates low variance across seeds (std=3.40), confirming results are not due to fortunate initialization.
    
    \item \textbf{Robustness:} Performance remains competitive across $\eta \in [0.5, 5.0]$ when $\gamma \geq 0.05$, indicating reasonable tolerance to hyperparameter misspecification.
\end{enumerate}

\paragraph{Convergence Validation.}
Log-log regression (excluding 50-sample burn-in) yields growth exponent $\beta=0.669 \pm 0.002$ with $R^2=0.9903$, confirming sublinear regret growth $O(T^{0.669})$ and satisfying the PAC-learnability criterion ($\beta < 1$).

\paragraph{Cold-Start Model Integration.}
Since warmup priors cover only Mixtral and GPT-4-Turbo, GPT-4o is initialized from GPT-4-Turbo's learned preferences with conservative scaling ($\gamma=0.05$). At $\lambda=0$ (quality only), the bandit rapidly discovers GPT-4o as the dominant choice (64.6\% usage, 5-seed average), correctly identifying the warmup expert's GPT-4-Turbo bias as suboptimal. At $\lambda=0.1$, GPT-4o usage rises to 74.3\% as cost awareness further penalizes GPT-4-Turbo. Note that this rapid convergence is driven by the online learning mechanism and family-level $\betavec$ sharing rather than the one-shot $\thetavec$ transfer (see Section~\ref{sec:transfer_null}).

\paragraph{Validation Protocol.}
Evaluate warmup predictions on $N=100$--$200$ deployment samples.
Start with Corralling (library default) and monitor the first 50--100
prompts.  If warmup expert accuracy falls below random chance, switch to
tabula rasa to cap downside risk.

\paragraph{Key Findings.}
(1)~Corralling outperforms warmup-only across corruption levels
(7--13\% lower regret) and tabula rasa for good priors
($\alpha \leq 0.2$, ${\sim}$6\% lower regret);
(2)~Tabula Rasa is optimal when priors are known-bad or truly uncertain;
(3)~Warmup-only is \emph{never} optimal at any corruption level and should
be migrated to Corralling in all cases;
(4)~The crossover at $\alpha \approx 0.3$ provides a principled decision rule.
All configurations use constant $\alpha=2.0$.

\subsection{Detailed Future Directions}
\label{sec:future_work_detailed}

\paragraph{Cold-Start Model Integration.}
Our null result on semantic transfer identifies this as an open problem. Future approaches might explore Thompson Sampling (which provides natural stochastic exploration of new models), active exploration bonuses specifically for under-sampled models, or meta-learning across model registration events. The structural challenge is that in a $K$-model portfolio, a new model's initialization affects only ${\sim}1/K$ of routing decisions, making per-model transfer inherently low-signal.

\paragraph{Algorithmic Extensions.}
\begin{itemize}
    \item \textbf{Expert-Level Non-Stationarity:} Our current experts assume stationary rewards; non-stationarity is handled only at the meta level. Integrating discounted UCB, sliding-window updates, or change-point detection within individual experts would enable adaptation to gradual reward drift without requiring meta-level intervention.
    \item \textbf{Anisotropic Regularization:} The isotropic prior $\Amat_0 = \lambda \mathbf{I}$ in PCA space over-regularizes low-variance components. Variance-matched diagonal priors or full whitening before the bandit layer could improve sample efficiency.
    \item \textbf{Adaptive Corralling Learning Rate:} Replacing the fixed $\eta$ with a horizon-aware schedule ($\eta_t \propto \sqrt{\ln K / t}$) or a doubling-trick variant would restore formal regret guarantees while maintaining practical performance.
    \item \textbf{Adaptive Exploration Schedules:} Our multi-model evaluation ($K{=}5$--$20$) reveals that the constant exploration coefficient ($\alpha{=}2.0$) imposes a quality tax in stationary regimes where one model dominates (0.954 vs.\ 0.983 best static at $K{=}5$). Adaptive schedules that modulate $\alpha$ based on estimated stationarity---reducing exploration when the reward landscape appears stable, increasing it when drift is detected---could narrow this gap while preserving distribution-shift detection.
\end{itemize}

\paragraph{From Routing to Orchestration.}
We view single-model routing as a precursor to \textbf{Agentic Orchestration}. The Corralling mechanism is naturally suited to govern autonomous agent portfolios: detecting when a specialist agent has degraded and dynamically reallocating tasks, just as it decommissions a failing expert in the routing setting.
