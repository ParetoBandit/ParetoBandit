\section{Methodology}
\label{sec:methodology}

% TRANSITION from Empirical Motivation
Having established empirical motivation---model preference heterogeneity exists (Figure~\ref{fig:alignment_tax}) but distribution shift is significant (PSI=0.225, Section~\ref{sec:distribution_shift})---we now present our integrated system design. Our approach combines three mechanisms, each addressing one of the challenges identified in Section~\ref{sec:intro}:

\begin{itemize}
    \item \textbf{Contextual embeddings} exploit semantic structure for learning
    \item \textbf{Corralling meta-learning} provides safety against prior mismatch
    \item \textbf{Semantic transfer} eliminates cold-start penalties for new models
\end{itemize}

We formalize LLM routing as a \emph{Cost-Aware Contextual Bandit} problem. Our framework, banditGPT, introduces a hierarchical architecture that addresses two fundamental challenges in production routing: safety against non-stationary quality shifts and agility in adopting new models.

\subsection{Unified Feature Space: From Discovery to Deployment}

All experiments in this work operate in a unified semantic feature space to ensure consistency from analysis to deployment. Prompts are embedded using \texttt{sentence-transformers/all-MiniLM-L6-v2} (384-dimensional), reduced to 32 dimensions via domain-adapted PCA trained on 80,000 routing prompts from the RouteLLM dataset (35.14\% cumulative variance explained). This PCA is \emph{unsupervised}---it identifies directions of maximum variance in routing-relevant prompt embeddings without seeing reward labels. The primary semantic axis (PC1, 3.10\% variance) identified in Section~\ref{sec:motivation}---which correlates with model preference heterogeneity at $\text{PC1}=0.222$ (Figure~\ref{fig:pca})---becomes the substrate for all adaptation experiments (Section~\ref{sec:robustness_adaptation}). Robustness analysis with generic PCA (C4 corpus, 100K samples) confirms the underlying structure exists independently of PCA provenance ($d = 0.33$), though the domain-adapted PCA captures it more efficiently ($d = 1.53$). The consistency of this feature space from analysis (Figure~\ref{fig:pca}) through baseline establishment (Table~\ref{tab:performance_gap}) to regime validation enables direct comparison and unified interpretation across all results.

\subsection{Problem Formulation}

Let $x_t \in \mathbb{R}^d$ denote the context vector (embedding) for a user prompt at time $t$. We maintain a dynamic registry of models (arms) $\mathcal{M}_t$. For each request, the policy $\pi$ selects an arm $a_t \in \mathcal{M}_t$, observing a scalar reward $r_t \in [0, 1]$ (quality) and incurring a deterministic cost $c_t \in \mathbb{R}^+$ (inference price).

Unlike standard regret minimization, our objective is to maximize quality subject to a budget constraint, formulated as a Lagrangian relaxation with a user-defined penalty $\lambda$:
\begin{equation}
\text{Maximize } \sum_{t=1}^T \left( \mathbb{E}[r_t(a_t) | x_t] - \lambda \cdot c_t(a_t) \right)
\end{equation}
where $\lambda$ controls the trade-off between performance and economy. A high $\lambda$ forces the router to identify ``easy'' prompts where cheaper models suffice, while a low $\lambda$ prioritizes quality regardless of cost.

\subsubsection{Layer 1: Dynamic Pareto Filtering}

To strictly enforce efficiency, we implement a per-request dominance check before the bandit layer. For a given context $x_t$, we estimate the expected quality $\hat{r}_m(x_t)$ for all $m \in \mathcal{M}_t$. We construct a local Pareto frontier $\mathcal{P}_{x_t} \subseteq \mathcal{M}_t$ such that a model $m$ is excluded if there exists another model $m'$ where:
\begin{equation}
\hat{r}_{m'}(x_t) \ge \hat{r}_m(x_t) \quad \text{and} \quad c_{m'} < c_m
\end{equation}

This \emph{Dynamic Pareto Filtering} ensures the bandit policy never explores strictly dominated actions, accelerating convergence by pruning the search space.

\subsubsection{Layer 2: Expert Corralling for Robustness}

Non-stationarity (e.g., a ``good'' model becoming ``bad'' due to drift) poses a fatal risk to standard bandit algorithms. We mitigate this \emph{at the meta level} via a strategy inspired by Expert Corralling~\cite{agarwal2017corralling}, which manages a portfolio of expert policies (e.g., a ``Warmup Expert'' with static priors and a ``Tabula Rasa Expert'' with high plasticity). Importantly, each expert bandit is itself trained under a \emph{stationary-reward assumption} (monotone information accumulation without explicit forgetting); non-stationarity is handled solely through the meta-learner's ability to reweight or decommission experts whose performance has degraded.

The master algorithm updates the probability distribution over experts $w_{i,t}$ using an exponential weight update based on importance-weighted loss estimates $\hat{\ell}_{i,t}$. Crucially, to prevent ``Expert Death'' (where a temporarily poor expert's weight vanishes, rendering it unrecoverable), we implement a mixing parameter $\gamma$:
\begin{equation}
p_{i,t} = (1 - \gamma) \frac{w_{i,t}}{\sum_j w_{j,t}} + \frac{\gamma}{K}
\end{equation}

We set $\gamma=0.05$, imposing a uniform exploration floor that enables asymptotic recovery if the optimal expert changes over time.

\subsubsection{Layer 3: Cost-Aware LinUCB}

Each expert $i$ models the reward function using Bayesian Ridge Regression (LinUCB~\cite{li2010contextual}). We approximate the reward surface of model $m$ as a linear function of the context: $\mathbb{E}[r | x] = x^\top \theta^*_m$. The policy selects the arm maximizing the Upper Confidence Bound (UCB) of the composite utility:
\begin{equation}
a_t = \arg\max_{a \in \mathcal{P}_{x_t}} \left( x_t^\top \hat{\thetavec}_a + \alpha \sqrt{x_t^\top \Amat_a^{-1} x_t} - \lambda c_a \right)
\end{equation}

\paragraph{Exploration Parameter Selection.}
We use constant $\alpha=2.0$ for both experts throughout deployment. While standard practice employs adaptive decay schedules (e.g., $\alpha_t = \alpha_0/\sqrt{t}$), our ablation studies (Section~\ref{sec:alpha_ablation}) demonstrate that constant exploration is essential under severe domain mismatch. Premature exploitation causes the system to commit irreversibly to misspecified priors. Maintaining constant $\alpha$ preserves the system's ability to detect and adapt to distribution shifts, achieving 48\% improvement over adaptive decay in high-mismatch scenarios.

To ensure numerical stability during long-running operations, we implement an \emph{Amortized Regularization Floor}. We track the effective decay of the precision matrix $\Amat_a$ and proactively reinject regularization $\lambda_{\text{ridge}}\mathbf{I}$ whenever the smallest eigenvalue risks dropping below a safety threshold, preventing singular matrix inversions without the cost of $O(d^3)$ operations at every step.

\paragraph{Regularization in PCA Space.}
We initialize the precision matrix as $\Amat_0 = \lambda \mathbf{I}$, which corresponds to an isotropic prior in the PCA-transformed feature space. This does not distinguish between high- and low-variance principal components and may over-regularize the latter. We adopt this deliberately simple baseline for stability; designing anisotropic or variance-matched regularization (e.g., diagonal $\Amat_0$ scaled by component variance, or full whitening before the bandit layer) is a natural extension that we leave for future work.

\subsection{Latent Semantic Transfer (Zero-Shot Admission)}

A critical bottleneck in LLM routing is the ``Cold Start'' problem: when a new model is released, standard bandits must explore it randomly to learn its utility. We propose \emph{Latent Semantic Transfer} to enable zero-shot readiness.

When a new model $m_{\text{new}}$ is registered, we identify its nearest semantic neighbor $m_{\text{near}}$ (e.g., embedding similarity between model descriptions or card data). We initialize the new model's parameters by transferring the neighbor's learned preference vector $\thetavec_{\text{near}}$ while resetting the confidence:
\begin{equation}
\thetavec_{\text{new}} \leftarrow \thetavec_{\text{near}}, \quad \Amat_{\text{new}} \leftarrow \neff\mathbf{I}
\end{equation}

This decouples the expectation (mean) from the certainty (variance). The router effectively starts with a hypothesis---``This model behaves like GPT-4-Turbo''---but maintains high variance (controlled by $\neff$), allowing it to aggressively exploit the model where the hypothesis holds while rapidly correcting where it diverges.

\subsection{Corralling: Adaptive Expert Combination}

To manage the trade-off between robust priors and online adaptability, we employ a simplified variant of the Corralling algorithm~\cite{agarwal2017corralling}. This meta-learning framework aggregates two distinct experts:

\begin{itemize}
    \item \textbf{Warmup Expert}: Initialized with priors $\thetavec_{\text{warm}}$ derived from offline RouteLLM data.
    \item \textbf{Tabula Rasa Expert}: Initialized with uninformative priors ($\Amat=\mathbf{I}$, $\bvec=\mathbf{0}$).
\end{itemize}

\textbf{The Algorithm}: At each round $t$, the coordinator samples an expert $e_t \sim p_t$ and observes the reward $r_t$. Since we only observe the reward for the chosen expert, we compute an importance-weighted loss estimate:
\begin{equation}
\hat{\ell}_{t,e} = \begin{cases}
\frac{1 - r_t}{p_t(e)} & \text{if } e = e_t \\
0 & \text{otherwise}
\end{cases}
\label{eq:importance_weighted_loss}
\end{equation}

The expert weights $w_{t,e}$ are updated using exponential descent with learning rate $\eta$:
\begin{equation}
w_{t+1,e} \propto \exp\left(-\eta \sum_{s=1}^t \hat{\ell}_{s,e}\right)
\label{eq:corralling}
\end{equation}

\textbf{Learning Rate Selection}: We evaluate two learning rates: conservative ($\eta=0.1$) and aggressive ($\eta=1.0$). Multi-seed evaluation (Section~\ref{sec:results}, Table~\ref{tab:performance_gap}) reveals a stability-performance tradeoff. While an independent t-test yields $p=0.63$ (Cohen's $d=-0.22$), the experiment has limited power to detect this small effect ($N=30$, power $\approx 23\%$), so we cannot conclude the conditions are equivalent. Conservative learning offers predictable performance (CV=17\%), while aggressive learning achieves better median but with higher variance (CV=35\%). We recommend $\eta=0.1$ for production deployments requiring reliability, based on its substantially lower variance rather than on a claim of equivalent mean performance.

\textbf{Relationship to Theory}: Our implementation is inspired by the theoretical Corralling framework but differs in key aspects for production efficiency: (1) only the selected expert updates its internal state (rather than all experts observing full feedback), and (2) we use a fixed learning rate ($\eta=0.1$ or $\eta=1.0$) tuned for the typical horizon in our application, rather than the theoretically optimal $\eta^* \propto \sqrt{\ln K / T}$. While these simplifications sacrifice the formal $O(\sqrt{T})$ regret guarantee, empirical validation (Section~\ref{sec:results}) demonstrates that the system achieves competitive performance relative to the best expert in hindsight.

\textbf{Staleness-Aware Meta-Learning Rate}: In production, feedback arrives with variable delay (network latency, human evaluation). Stale feedback is less informative about the \emph{current} expert quality. We attenuate the meta-learner's loss contribution by a staleness factor:
\begin{equation}
\hat{\ell}_{t,e}^{\text{staleness}} = \frac{1}{1 + \delta_t / \tau} \cdot \hat{\ell}_{t,e}
\end{equation}
where $\delta_t$ is the delay (seconds) between selection and feedback, and $\tau$ is a half-life parameter (default 60s). This prevents stale feedback from causing abrupt, unjustified weight shifts in the meta-learner, while preserving the standard importance-weighted loss estimator (Eq.~\ref{eq:importance_weighted_loss}) for timely feedback.

\subsubsection{Technical Fairness and Computational Complexity}
Our implementation adapts the theoretical Corralling framework~\cite{agarwal2017corralling} to the constraints of low-latency production inference.

\paragraph{The Efficiency Trade-off ($O(K) \to O(1)$).}
The theoretical algorithm requires updating the state of all $K$ experts at every step (using counterfactual loss estimators). While theoretically optimal, this incurs linear computational scaling. To maintain strict latency SLAs (< 20ms overhead), we employ a \textbf{Selected-Update Approximation}: we update only the expert chosen by the coordinator ($e_t$).
\begin{itemize}[nosep]
    \item \textbf{Benefit:} This reduces the update complexity from $O(K)$ to $O(1)$, allowing the expert registry to scale to hundreds of models without increasing router latency.
    \item \textbf{Limitation:} Unselected experts effectively ``freeze,'' leading to potential starvation.
\end{itemize}

\paragraph{Mitigating Starvation.}
We counteract the lack of counterfactual updates through \textbf{Uniform Initialization} ($\pi_0 = [0.5, 0.5]$) and the \textbf{Incumbent Failure Logic}. As demonstrated in Figure~\ref{fig:corralling}, even without $O(K)$ updates, the system successfully identifies and decommissions the suboptimal expert within 200 steps.

\subsection{Prior Calibration and Runtime Monitoring}

Loading pre-trained priors from offline data can introduce \emph{Scale Explosion}---predictions of 800.0 instead of 0.8---due to mismatched reward scales or accumulation magnitudes. We address this with a two-pass calibration at initialization and continuous runtime monitoring during deployment.

\paragraph{Two-Pass Calibration.}
\textbf{Pass~1 (bias probe)}: We probe each model with a bias-only context $[0,\ldots,0,1]$. If the predicted reward exceeds a threshold (1.5), we clamp the bias weight via \emph{theta-reconstruction}: we modify $\thetavec$ directly and set $\bvec = \Amat \thetavec_{\text{new}}$, which preserves all PCA-dimension preferences exactly while correcting only the bias component.
\textbf{Pass~2 (suite probe)}: We probe each model with a suite of basis-independent feature vectors---axis-aligned unit vectors, random unit-norm vectors, and a uniform ``all features active'' vector---to detect PCA-dimension explosions that a single-coordinate probe would miss. If the worst-case prediction exceeds the threshold, $\thetavec$ is globally rescaled. Because banditGPT is a domain-agnostic library, the probe suite uses synthetic geometry rather than domain-specific prompts; users may optionally supply their own representative contexts for deployment-specific calibration.

\paragraph{Runtime Prediction Monitoring.}
Static calibration at initialization cannot detect problems that emerge post-deployment (gradual drift, bad priors on newly registered models, feature distribution shift). We augment each expert with a lightweight $O(1)$-per-observation monitor that tracks per-model rolling statistics (min, max, mean, variance) of both expected reward ($\thetavec^\top x$) and full UCB score. When predictions exceed a configurable alert threshold, the system logs a warning. The health report is queryable for CI and canary deployment checks.

\subsection{Semantic Projection \& Scalability}

To validate the router's generalization capability, we projected the learned policy onto the full LMSYS Chat-1M dataset ($N=594$k). As shown in Figure~\ref{fig:corralling} (Left), the ``Easy Cluster'' ($\text{PC1} < 0.3$) accounts for $94.2\%$ of traffic.

\textbf{Implication}: By identifying this structure, the router effectively unlocks a $94\%$ opportunity for cost reduction that static ``hard'' classifiers miss.

\textbf{Separation of Optimization and Visualization}: Crucially, we train only on the labeled Dev set ($N=1{,}121$) and project the policy onto the unlabeled 1M set. This ensures the cluster analysis is a valid test of semantic generalization, not just memorization.
