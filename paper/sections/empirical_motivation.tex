\section{Empirical Motivation: The Semantic Structure of Routing}
\label{sec:motivation}

The LLM routing literature broadly divides into two paradigms. \emph{Static routers} learn a prompt-to-model mapping offline and deploy it frozen, inherently assuming monotonicity: that allocating more budget to a more capable, expensive model consistently yields higher or equal quality. \emph{Adaptive routers}~\cite{panda2025pilot, wang2025barp, li2025llmbandit} update online to adapt to performance variations, provided their features capture relevant signals.

We present an empirical finding that challenges the static monotonicity assumption and motivates our architecture: prompt embeddings predict model preference, but this preference is non-trivial. On 14.1\% of held-out prompts, human judges preferred a cheaper open-weights model over a frontier model, a preference that correlates significantly with prompt semantics ($\rho = -0.370$, $p < 0.0001$). The expensive model doesn't just waste budget on simple tasks; it \emph{underperforms} on a predictable fraction of prompts. This reframes routing from a simple cost-quality interpolation into a \textbf{discovery} problem: the router must learn which prompts genuinely benefit from the expensive model.

\subsection{Predicting Model Preference Heterogeneity}

To analyze model preference, we project 750 held-out LMSYS Arena prompts onto the first principal component (PC1) of our unsupervised 32-component PCA model (Section~\ref{sec:feature_pipeline}).

\paragraph{Feature spaces capture model preference.}
We observe a significant Spearman rank correlation between the prompt's PC1 projection and the reward gap between the frontier and cheaper models ($R_{\text{Frontier}} - R_{\text{Cheaper}}$): $\rho = -0.370$, $p < 0.0001$, $N = 750$ (Figure~\ref{fig:lmsys_holdout_structure}A). Higher PC1 values indicate prompts where the cheaper model outperforms the expensive one. A Mann-Whitney $U$ test on a median split of PC1 confirms this directional finding ($p < 0.0001$).

To verify this signal isn't a projection artifact, we compare the Router PCA ($|\rho| = 0.370$) against 100 independent random orthonormal projections. The Router PCA exceeds all 100 random baselines (Figure~\ref{fig:lmsys_holdout_structure}B), achieving a 2.6$\times$ signal ratio versus the random median ($|\rho|_{\text{random}} = 0.145$).

\paragraph{Cost savings emerge from heterogeneous preferences.}
Model preference is far from uniform (Table~\ref{tab:outcome_distribution}). For 72.8\% of prompts, both models perform comparably (a tie). The router's true value lies in directing the vast majority of traffic (86.9\%) to the cheaper model without quality loss, reserving the expensive model only for the 13.1\% of prompts where it provides a genuine advantage.

\subsection{Implications for Router Architecture}

These findings establish three architectural requirements for \textit{banditGPT}:

\begin{enumerate}[noitemsep,topsep=2pt]
    \item \textbf{Exploiting Semantic Structure:} Because preference heterogeneity is predictable from prompt embeddings, a router can distinguish when the expensive model is needed. While our holdout sampling deliberately enriched for clear preferences (meaning production traffic correlation might be lower), the core finding remains: embeddings carry actionable model-preference signals.
    
    \item \textbf{Avoiding Static Monotonicity Priors:} A frozen policy assuming monotonicity will systematically over-provision the expensive model where it underperforms. Our Pareto analysis (Section~\ref{sec:pareto}) shows static methods can actually \emph{degrade} in quality while spending more by over-allocating the expensive model.
    
    \item \textbf{Safe Online Learning:} Because preference structure shifts with deployment distributions, it cannot be reliably specified offline. A router must adapt online, use meta-learning to hedge against misleading priors, and handle non-stationarity. Our ablation (Section~\ref{sec:distribution_shift}) confirms online learning drives a $+7.0$\,pp gain, Corralling meta-learning adds $+1.3$\,pp ($p < 0.0001$), while prior source has no significant effect despite severe distribution shift (PSI\,$=$\,0.763).
\end{enumerate}

This chain of reasoning---from empirical heterogeneity to the failure of static monotonicity---motivates the \textit{banditGPT} architecture detailed next (Section~\ref{sec:methodology}).
