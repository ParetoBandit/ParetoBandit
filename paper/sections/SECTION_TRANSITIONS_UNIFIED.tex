Our integrated approach rests on a critical empirical foundation: that semantic structure exists in the LLM task space and can be exploited for intelligent routing. In this section, we demonstrate that model preference varies by prompt and the router's features predict this variation (Figure~\ref{fig:lmsys_holdout_structure}), establishing that routing is \emph{learnable} through contextual features---but the surprising structure of these preferences (the cheaper model wins more often than the expensive one) makes safe online learning essential.

We presented \textbf{banditGPT}, an open-source, cost-aware contextual bandit framework for LLM routing combining online adaptation with Corralling meta-learning. Through comprehensive validation ($N{=}750$ held-out prompts), we demonstrated:

\begin{itemize}
    \item \textbf{Performance:} $63.1\%$ gap closure to oracle (vs $45.9\%$ for RouteLLM); surpasses 100k-pair supervised router after ${\sim}300$--$400$ in-distribution label-free prompts at moderate-to-high budgets
    \item \textbf{Adaptive meta-learning:} Corralling exploits complementary alpha schedules to dominate both alternatives when priors are useful, with catastrophic failure detection as a secondary benefit
    \item \textbf{Honest boundary:} Semantic transfer for cold-start models provides no significant improvement over tabula rasa, establishing an open problem for future work
\end{itemize}

In this section, we discuss limitations and future work.
