\section{Complete Experimental Data (artifact pointer)}
\label{appendix:complete_data}

To keep the appendix concise while preserving full transparency, we do not reproduce the full sweep tables (including dominated points) in-line. The complete numerical results underlying Figure~\ref{fig:pareto} are available in the repository artifacts:

\begin{itemize}[nosep]
    \item \texttt{experiments/04\_figure/results/pareto\_results.json}: canonical 20-seed Pareto sweep data used in the paper figures.
    \item \texttt{experiments/04\_figure/results/pareto\_results\_final.json} (if present): full run logs including intermediate points.
\end{itemize}

\noindent These files include the full cost/quality values for each evaluated operating point and are sufficient to reconstruct the plotted frontiers and reproduce any downstream analysis.
