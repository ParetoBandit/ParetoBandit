\caption{ParetoBandit system architecture. The synchronous inference path (blue) extracts prompt features via the FeatureService (embedding, PCA, bias) and routes through the BanditRouter, which applies constraint filtering and budget-augmented UCB scoring to select a model. The BudgetPacer enforces the budget through two mechanisms: an adaptive cost ceiling that gates the candidate set ($\mathcal{A}_t$), and a soft dual penalty $\lambda_t \cdot \tilde{c}_a$ injected into the scoring function. The asynchronous feedback path (orange) updates reward estimates with geometric forgetting, adjusts the dual variable via the EMA-smoothed cost signal, and persists context vectors in the ContextStore for delayed-feedback workflows (e.g., human RLHF labels arriving hours after routing).}
